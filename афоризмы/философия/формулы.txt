# Философия — Формулы бытия и познания

## 🌌 Онтологические формулы (формулы бытия)

**Существование:**
```
Существую → Мыслю
Cogito, ergo sum
∃(Я) ⇔ Мышление(Я)
```

**Бытие:**
```
Бытие ≠ Небытие
Being ≠ Nothingness
∃ > ∅
```

**Реальность:**
```
Реальность = Объективное ∩ Субъективное
R = Obj ∩ Subj
```

## 🔍 Логические формулы

**Закон непротиворечия:**
```
¬(P ∧ ¬P)
не может быть одновременно P и не-P
```

**Закон исключённого третьего:**
```
P ∨ ¬P
либо P, либо не-P
```

**Modus Ponens:**
```
(P → Q) ∧ P ⊢ Q
если P влечёт Q, и P истинно, то Q истинно
```
