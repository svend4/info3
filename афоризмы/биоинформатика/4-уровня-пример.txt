Центральная догма молекулярной биологии:
DNA → RNA → Protein

Геном человека:
• 3.2 миллиарда пар оснований (bp)
• ~20,000 генов (кодируют белки)
• 98% некодирующая ДНК ("junk" — но не совсем!)

Стоимость секвенирования генома:
2001: $100,000,000 (Human Genome Project)
2008: $1,000,000
2014: $1,000
2024: $200-600

→ Закон Мура для геномики: быстрее чем Moore's Law!

Sequence Alignment Score:
S = Σ(match_score - mismatch_penalty - gap_penalty)

→ Насколько похожи две ДНК/белковые последовательности

Статистическая значимость (p-value):
E-value = m × n × P

где:
m — длина query
n — размер базы данных
P — вероятность случайного совпадения

→ E-value < 10^-5 считается значимым

Bioinformatics = (Genomics × Proteomics) × (Algorithms × Databases) × (ML/AI)

Компоненты:

Genomics (Геномика):
├─ DNA Sequencing:
│  ├─ Sanger sequencing: старый метод, 800 bp reads
│  ├─ Illumina: short reads (150-300 bp), high accuracy
│  ├─ PacBio: long reads (10-20 kb), lower accuracy
│  ├─ Nanopore: ultra-long (100+ kb), portable
│  └─ 10x Genomics: linked reads для phasing
├─ Genome Assembly:
│  ├─ De Bruijn graphs: короткие reads → contigs
│  ├─ Overlap-layout-consensus: длинные reads
│  └─ Reference-guided: выравнивание к известному геному
├─ Variant Calling:
│  ├─ SNPs (Single Nucleotide Polymorphisms): 1 bp changes
│  ├─ Indels: insertions, deletions
│  ├─ CNVs (Copy Number Variations): дупликации, делеции
│  └─ Structural variants: большие перестройки
├─ Gene Annotation:
│  ├─ Gene prediction: где гены в геноме?
│  ├─ Functional annotation: что делают гены?
│  └─ Comparative genomics: сравнение между видами
└─ GWAS (Genome-Wide Association Studies):
   └─ Связь генетических вариантов с болезнями

Transcriptomics (Транскриптомика):
├─ RNA-seq: измерение экспрессии генов
├─ Single-cell RNA-seq: индивидуальные клетки
├─ Differential expression: какие гены up/down регулированы
└─ Splice variants: альтернативный сплайсинг

Proteomics (Протеомика):
├─ Mass spectrometry: идентификация белков
├─ Protein structure prediction:
│  ├─ AlphaFold2 (DeepMind): революция 2020
│  └─ RoseTTAFold (Baker lab)
├─ Protein-protein interactions: PPI networks
└─ Post-translational modifications: phosphorylation, etc.

Метаболомика:
├─ Metabolite profiling: малые молекулы в клетках
└─ Pathway analysis: метаболические пути

Algorithms (Алгоритмы):

Sequence Alignment:
├─ Needleman-Wunsch: global alignment (dynamic programming)
├─ Smith-Waterman: local alignment
├─ BLAST: heuristic search (быстрее, но не оптимально)
└─ Burrows-Wheeler Transform: для mapping reads

Phylogenetics:
├─ Maximum Likelihood: статистическая модель эволюции
├─ Bayesian inference: posterior probabilities
└─ Neighbor-joining: быстрый distance-based метод

Clustering:
├─ Hierarchical clustering: дерево похожести
├─ K-means: разделение на k кластеров
└─ t-SNE, UMAP: визуализация high-dimensional data

Databases (Базы данных):

Sequence Databases:
├─ GenBank (NCBI): все public sequences
├─ ENA (EBI): European Nucleotide Archive
├─ DDBJ: Japan
└─ UniProt: белковые последовательности, аннотации

Structural Databases:
├─ PDB (Protein Data Bank): 3D структуры белков
└─ AlphaFold DB: предсказанные структуры всех белков

Pathway Databases:
├─ KEGG: метаболические пути
├─ Reactome: biological pathways
└─ GO (Gene Ontology): функциональная классификация

Disease Databases:
├─ OMIM: генетические болезни
├─ ClinVar: клиническая значимость вариантов
└─ TCGA: cancer genomics

ML/AI в биоинформатике:

Supervised Learning:
├─ Gene prediction: классификация регионов ДНК
├─ Variant pathogenicity: вредный вариант или нет?
├─ Drug response prediction: фармакогеномика
└─ Disease risk prediction: polygenic risk scores

Unsupervised Learning:
├─ Clustering: группировка генов, клеток
├─ Dimensionality reduction: PCA, t-SNE для визуализации
└─ Topic modeling: функциональные модули

Deep Learning:
├─ AlphaFold: protein structure prediction (transformer)
├─ DeepSEA: regulatory elements prediction (CNN)
├─ DeepVariant: variant calling (CNN)
└─ scGen: single-cell data analysis (VAE)

Generative Models:
├─ Molecule generation: новые лекарства
├─ Protein design: synthetic proteins
└─ Genome editing design: CRISPR guide design

Applications (Применения):

Precision Medicine:
├─ Pharmacogenomics: индивидуальный подбор лекарств
├─ Cancer genomics: таргетная терапия
├─ Rare disease diagnosis: whole exome/genome sequencing
└─ Prenatal testing: non-invasive screening

Drug Discovery:
├─ Target identification: какие белки атаковать
├─ Virtual screening: in silico поиск кандидатов
├─ Lead optimization: улучшение молекул
└─ Clinical trial design: patient stratification

Synthetic Biology:
├─ Genome editing: CRISPR-Cas9
├─ Metabolic engineering: биотопливо, chemicals
├─ Synthetic genomes: минимальные геномы
└─ Gene therapy: лечение генетических болезней

Agriculture:
├─ Crop improvement: yield, disease resistance
├─ Livestock breeding: genomic selection
└─ Pathogen surveillance: plant/animal diseases

Forensics:
├─ DNA fingerprinting: идентификация личности
├─ Paternity testing
└─ Crime scene analysis

Ecology & Evolution:
├─ Metagenomics: микробные сообщества
├─ Population genomics: эволюция, миграция
└─ Conservation genetics: endangered species

Challenges (Вызовы):

Computational:
├─ Data volume: петабайты sequences
├─ Storage: долгосрочное хранение
├─ Compute: assembly, alignment требуют HPC
└─ Reproducibility: версионирование, workflows

Biological:
├─ Interpretation: что значат варианты?
├─ Missing heritability: GWAS объясняет <50%
├─ Non-coding regions: функции неясны
└─ Complexity: epistasis, environment interactions

Ethical:
├─ Privacy: genetic discrimination
├─ Consent: использование данных
├─ Equity: доступ к genomic medicine
└─ Designer babies: germline editing ethics

ОБЪЯСНЕНИЕ:

РЕВОЛЮЦИЯ СЕКВЕНИРОВАНИЯ:

2003: Human Genome Project завершён
• $3 миллиарда, 13 лет
• 3.2 миллиарда пар оснований

2024: Whole genome за день
• $200-600
• Миллионы геномов секвенированы

Data generation >> Data interpretation

ПРОБЛЕМА ИНТЕРПРЕТАЦИИ:

1. VARIANTS OF UNKNOWN SIGNIFICANCE (VUS):
   • ~30,000 variants в каждом геноме
   • ~100-200 coding variants уникальны для индивида
   • Большинство: неизвестная клиническая значимость
   
   Пример: BRCA1 ген (рак груди)
   • Известные патогенные: ясно → профилактическая мастэктомия
   • VUS: что делать? Неясно

2. MISSING HERITABILITY:
   • GWAS находят варианты для болезней
   • НО объясняют <50% наследуемости
   • Где остальное? Редкие варианты? Epistasis? Environment?

3. NON-CODING REGIONS:
   • 98% генома не кодирует белки
   • Функции большинства неизвестны
   • ENCODE проект: многое regulatory, но детали неясны

УСПЕХИ:

1. ALPHAFOLD2 (2020) — Protein Structure Revolution:
   • Предсказывает 3D структуру белка из последовательности
   • Accuracy: >90% (соревнуется с экспериментальными методами)
   • Impact: 200+ million structures предсказаны
   • Nobel Prize 2024 (Chemistry) — Demis Hassabis, John Jumper
   
   До AlphaFold: ~170,000 экспериментальных структур за 50 лет
   После AlphaFold: практически все известные белки за 2 года
   
   Применения:
   • Drug discovery: знание структуры → дизайн лекарств
   • Understanding diseases: мутации → структурные изменения
   • Enzyme engineering: дизайн новых катализаторов

2. CRISPR GENE THERAPY:
   • 2020: FDA approval первой CRISPR терапии (sickle cell disease)
   • Casgevy: редактирование гемоглобина
   • Пациенты излечены от болезни
   
   Потенциал: лечение тысяч генетических болезней
   
   НО: challenges
   • Off-target effects: нежелательное редактирование
   • Delivery: как доставить в нужные клетки?
   • Cost: $2+ million за лечение
   • Ethics: germline editing (наследуемые изменения)

3. CANCER GENOMICS:
   • Секвенирование опухолей: какие мутации?
   • Таргетная терапия: лекарства для специфических мутаций
   
   Примеры:
   • Herceptin: HER2+ breast cancer
   • Gleevec: BCR-ABL fusion в CML (chronic myeloid leukemia)
   • Checkpoint inhibitors: для high mutation burden опухолей
   
   Результат: improved survival для многих раков

ПРОВАЛЫ:

1. THERANOS (2003-2018):
   • Обещание: сотни тестов из капли крови
   • Реальность: технология не работала
   • Fraud: Elizabeth Holmes — тюрьма
   • Урок: биология сложнее, чем кажется; hype != reality

2. POLYGENIC RISK SCORES — Oversold:
   • Идея: тысячи вариантов → предсказание риска болезни
   • Проблема: 
     - Accuracy низкая для большинства болезней
     - Работает в основном для европейцев (bias в данных)
     - Anxiety без actionable информации
   • Коммерческие компании (23andMe) продают, но clinical utility сомнительна

3. PHARMACOGENOMICS — Slow Adoption:
   • Обещание: персонализированные лекарства на основе генетики
   • Реальность: лишь несколько лекарств имеют clear genetic guidelines
   • Проблема: complexity, cost, physician education
   • Успехи ограничены (например, warfarin dosing, clopidogrel)

БУДУЩЕЕ:

Оптимистичный сценарий:
• Геномное секвенирование при рождении (newborn screening)
• Предсказание и предотвращение болезней
• Персонализированная медицина для всех
• CRISPR лечит генетические болезни

Пессимистичный:
• Data без понимания
• Genetic discrimination (страхование, работа)
• Equity issues: только богатые получают доступ
• Ethical dilemmas: designer babies

Реалистичный:
• Постепенный прогресс в интерпретации
• Hybrid подход: genomics + traditional medicine
• Regulation для защиты от дискриминации
• Фокус на actionable findings

УРОК:
Технология опережает науку. Мы можем генерировать data быстрее, чем понимать его.

Биоинформатика — критический мост между данными и знаниями.
Но мост всё ещё строится.
