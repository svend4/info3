Transformer Architecture (основа современного NLP):
Attention(Q, K, V) = softmax(QK^T / √d_k) V

где:
Q — Query matrix (что ищем)
K — Key matrix (с чем сравниваем)
V — Value matrix (что возвращаем)
d_k — размерность ключей (для масштабирования)

Self-Attention:
• Каждое слово "смотрит" на все остальные слова
• Вычисляет важность каждого слова для понимания текущего
• Параллелизуемо (в отличие от RNN)

Perplexity (оценка языковой модели):
Perplexity = 2^(-1/N × Σ log₂ P(wᵢ))

→ Чем ниже perplexity, тем лучше модель предсказывает текст
→ GPT-3: perplexity ~20 на тестовых данных

BLEU Score (оценка качества перевода):
BLEU = BP × exp(Σ wₙ log pₙ)

где:
pₙ — точность n-грамм (1-gram, 2-gram, 3-gram, 4-gram)
BP — brevity penalty (штраф за короткие переводы)

→ 0-100 шкала, выше = лучше
→ Человеческий перевод: ~60-70 BLEU

NLP System = (Text Processing × Models) × (Tasks × Applications) × (Ethics)

Компоненты:

Text Processing (Обработка текста):
├─ Tokenization:
│  ├─ Word tokenization: разбиение на слова
│  ├─ Subword: BPE (Byte Pair Encoding), WordPiece
│  ├─ Character: посимвольное разбиение
│  └─ Sentence segmentation: разбиение на предложения
├─ Normalization:
│  ├─ Lowercasing: "Hello" → "hello"
│  ├─ Stemming: "running" → "run" (грубо)
│  ├─ Lemmatization: "better" → "good" (лингвистически правильно)
│  └─ Remove punctuation, numbers, stopwords
├─ Vectorization:
│  ├─ Bag of Words: частота слов
│  ├─ TF-IDF: важность слова в документе
│  ├─ Word2Vec: embedding слов в векторы
│  ├─ GloVe: global vectors for word representation
│  └─ Transformers: contextual embeddings (BERT, GPT)
└─ Language Detection:
   └─ Определение языка текста

Models (Модели):

Classical ML:
├─ Naive Bayes: для классификации текста
├─ SVM: классификация, sentiment analysis
├─ Logistic Regression: простая baseline
└─ CRF: structured prediction (NER)

Deep Learning:
├─ RNN (Recurrent Neural Networks):
│  ├─ Vanilla RNN: sequential processing
│  ├─ LSTM: long short-term memory (решает vanishing gradient)
│  └─ GRU: gated recurrent unit (упрощённая LSTM)
├─ CNN for Text: 1D convolutions для классификации
└─ Attention mechanisms: фокус на важных частях

Transformers (революция NLP):
├─ BERT (2018, Google):
│  ├─ Bidirectional: смотрит в обе стороны
│  ├─ Pre-training: на огромном корпусе
│  ├─ Fine-tuning: для конкретной задачи
│  └─ Применение: question answering, NER, classification
├─ GPT (2018-2024, OpenAI):
│  ├─ Autoregressive: предсказывает следующее слово
│  ├─ GPT-1: 117M parameters
│  ├─ GPT-2: 1.5B parameters
│  ├─ GPT-3: 175B parameters
│  ├─ GPT-4: ~1.7T parameters (оценка)
│  └─ Few-shot learning: может решать задачи без fine-tuning
├─ T5 (Text-to-Text Transfer Transformer):
│  └─ Универсальная архитектура для всех NLP задач
├─ BART, ELECTRA, RoBERTa: улучшения BERT
└─ LLaMA, Mistral, Claude: современные LLM

Tasks (Задачи NLP):

1. Text Classification:
   ├─ Sentiment analysis: positive/negative/neutral
   ├─ Topic classification: спорт, политика, tech
   ├─ Spam detection: email, SMS
   └─ Intent classification: chatbots

2. Named Entity Recognition (NER):
   ├─ Person: "Илон Маск"
   ├─ Organization: "Tesla"
   ├─ Location: "Калифорния"
   ├─ Date: "2024"
   └─ Custom entities: product names, medical terms

3. Machine Translation:
   ├─ Statistical MT: phrase-based (старый подход)
   ├─ Neural MT: seq2seq + attention (Google Translate)
   ├─ Transformer MT: SOTA (DeepL)
   └─ Unsupervised MT: без параллельных корпусов

4. Question Answering:
   ├─ Extractive: ответ из текста (BERT)
   ├─ Abstractive: генерация ответа (GPT)
   ├─ Open-domain: Google, ChatGPT
   └─ Closed-domain: FAQ bots

5. Text Summarization:
   ├─ Extractive: выбор ключевых предложений
   ├─ Abstractive: генерация нового текста (GPT, BART)
   └─ Single vs Multi-document

6. Text Generation:
   ├─ Creative writing: stories, poetry
   ├─ Code generation: GitHub Copilot, GPT-4
   ├─ Dialogue: ChatGPT, Claude
   └─ Data-to-text: отчёты из структурированных данных

7. Information Extraction:
   ├─ Relation extraction: "X is CEO of Y"
   ├─ Event extraction: who did what when where
   └─ Knowledge graph construction

8. Speech:
   ├─ Speech-to-text: Whisper (OpenAI), Google Speech
   └─ Text-to-speech: ElevenLabs, Google TTS

Applications (Применения):

Consumer:
├─ Virtual assistants: Siri, Alexa, Google Assistant
├─ Chatbots: customer service, FAQ
├─ Translation: Google Translate, DeepL
├─ Writing assistants: Grammarly, Jasper
├─ Search: Google, semantic search
└─ Social media: content moderation, recommendations

Enterprise:
├─ Document processing: contracts, invoices
├─ Email automation: categorization, response
├─ Knowledge management: search across documents
├─ Market intelligence: анализ новостей, соцсетей
├─ Legal tech: contract analysis, e-discovery
└─ Healthcare: clinical notes, drug discovery

Research:
├─ Scientific literature mining
├─ Biomedical NLP: PubMed, drug interactions
└─ Digital humanities: анализ исторических текстов

Ethics & Challenges:

Biases:
├─ Gender bias: "doctor" → male, "nurse" → female
├─ Racial bias: токсичные стереотипы в генерации
├─ Cultural bias: Western-centric training data
└─ Amplification: модели усиливают существующие предрассудки

Misinformation:
├─ Deepfakes: текст, аудио, видео
├─ Automated propaganda: боты генерируют фейки
├─ Hallucinations: LLM генерируют правдоподобную ложь
└─ Lack of factuality: модели не "знают", они предсказывают

Privacy:
├─ Training data: personal information в корпусах
├─ Memorization: модели могут воспроизводить training data
└─ Inference attacks: извлечение информации из модели

Environmental:
├─ Training GPT-3: ~552 tons CO2 (как 5 автомобилей за жизнь)
├─ Inference costs: каждый запрос = энергия
└─ Bigger models: тренд к большим моделям = больше энергии

Access & Equity:
├─ Language coverage: английский доминирует
├─ Low-resource languages: мало данных
├─ Compute costs: только big tech могут тренировать SOTA
└─ Digital divide: не все имеют доступ к технологиям

ТЕОРЕМА:

"Языковые модели становятся всё лучше в генерации текста, 
но не обязательно лучше в понимании истины"

ОБЪЯСНЕНИЕ:

РЕВОЛЮЦИЯ TRANSFORMERS:

2017: "Attention is All You Need" — изобретение Transformer
2018: BERT, GPT — начало эры pre-trained LLM
2020: GPT-3 — 175B параметров, few-shot learning
2022: ChatGPT — массовое adoption (100M пользователей за 2 месяца)
2023: GPT-4, Claude, LLaMA — новая волна

ВОЗМОЖНОСТИ:

Что LLM умеют хорошо:
• Генерация текста: естественный, связный, креативный
• Перевод: качество близко к человеческому
• Summarization: выделение ключевых идей
• Code generation: GitHub Copilot пишет код
• Conversation: естественный диалог
• Style transfer: формальный → casual и наоборот

Впечатляющие примеры:
• GPT-4 проходит bar exam (топ 10%)
• Med-PaLM2 проходит medical licensing exam
• AlphaCode решает competitive programming задачи
• ChatGPT пишет эссе, неразличимые от человеческих

НО: ФУНДАМЕНТАЛЬНЫЕ ОГРАНИЧЕНИЯ

1. HALLUCINATIONS (Галлюцинации):
   LLM генерируют правдоподобную, но ложную информацию
   
   Примеры:
   • Выдумывают научные статьи с реалистичными названиями
   • Создают несуществующих людей с биографиями
   • Генерируют ложные факты с уверенностью
   
   Причина: модели предсказывают токены, не "знают" истину

2. NO UNDERSTANDING:
   LLM — это статистические модели, не "мыслящие существа"
   
   • Китайская комната (Searle): синтаксис ≠ семантика
   • Parroting: воспроизведение паттернов без понимания
   • No grounding: нет связи с реальным миром

3. BIASES:
   Модели отражают предрассудки training data
   
   • Gender: "engineer" → male pronoun
   • Race: негативные ассоциации с определёнными именами
   • Political: lean depending on training data

4. CONTEXT LIMITS:
   Даже с большим context window (100K+ токенов), 
   модели "теряются" в длинных текстах

5. REASONING FAILURES:
   LLM struggle с:
   • Математикой (улучшается, но не надёжно)
   • Логикой (мodus ponens может ошибаться)
   • Common sense (неочевидные выводы)
   • Planning (multi-step reasoning сложен)

ПАРАДОКС:
• Лучше generation → больше доверия пользователей
• Но больше доверия → больше вреда от ошибок
• Fluency ≠ Correctness

БУДУЩЕЕ:

Optimistic:
• RAG (Retrieval-Augmented Generation): поиск + генерация
• Fact-checking integration: проверка фактов
• Multimodal: текст + изображения + видео → grounding
• Agent systems: LLM + tools → более надёжные ответы

Pessimistic:
• Фундаментальные ограничения архитектуры
• Scale не решает все проблемы
• Потолок приближается (diminishing returns)

Realistic:
• LLM — мощный инструмент, но не AGI
• Нужны hybrid systems: LLM + symbolic reasoning + retrieval
• Human-in-the-loop для критических приложений

ЗАКЛЮЧЕНИЕ:

NLP прошёл путь от rule-based систем к статистическим методам и, наконец, 
к трансформерам и LLM. Прогресс феноменальный.

НО: языковые модели — это не искусственный интеллект в полном смысле.
Это очень хорошие предсказатели следующего токена.

Ключевое понимание:
• Fluency ≠ Intelligence
• Generation ≠ Understanding
• Confidence ≠ Correctness

LLM — невероятно мощный инструмент, но требует критического отношения.

"Языковые модели могут говорить, но не обязательно знают, о чём говорят"
