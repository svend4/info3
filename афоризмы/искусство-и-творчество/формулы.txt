# Искусство и творчество — Формулы креативности

## 🎨 Базовые формулы искусства

**Искусство:**
```
Искусство = Форма × Содержание × Контекст × Эмоция
Art = Form × Content × Context × Emotion
```

**Творчество:**
```
Творчество = Знания × Связи × Свобода × Мотивация
Cr = Knowledge × Connections × Freedom × Motivation
```

**Шедевр:**
```
Шедевр = Мастерство × Оригинальность × Эмоция × Время
Ma = Mastery × Originality × Emotion × Time
```

**Красота:**
```
Красота ∈ Глаз_смотрящего
Beauty ∈ Eye_of_beholder
субъективна
```

## 💡 Формулы креативного процесса

**Процесс творчества (Уоллес):**
```
Творчество = Подготовка → Инкубация → Озарение → Верификация
Cr = Preparation → Incubation → Illumination → Verification
```

**Инсайт:**
```
Инсайт = Знания × Отдых × Расслабление
In = Knowledge × Rest × Relaxation
ага-момент
```

**Муза:**
```
Вдохновение = Опыт × Впечатления × Эмоции × Случайность
In = Experience × Impressions × Emotions × Chance
```

**Дисциплина:**
```
Искусство = 1% вдохновение + 99% труд
Art = 1% inspiration + 99% perspiration
```

## 🎭 Формулы оригинальности

**Оригинальность:**
```
Оригинальность = Новизна × Ценность
Or = Novelty × Value
```

**Инновация в искусстве:**
```
Инновация = Традиция + Нарушение_правил
In = Tradition + Rule_breaking
```

**Копирование vs Творчество:**
```
Копия ≠ Интерпретация ≠ Оригинал
Copy ≠ Interpretation ≠ Original
```

**Влияние:**
```
Творчество = ∑(Влияния) + Личное
Cr = ∑(Influences) + Personal
```
