# Деньги и успех — Финансовые и экономические формулы

## 💰 Базовые формулы денег

**Богатство:**
```
Богатство = Доходы - Расходы
W = I - E
```

**Накопление:**
```
Капитал(t) = Капитал(0) × (1 + r)^t
сложный процент
```

**Финансовая свобода:**
```
Свобода = Пассивный_доход / Ежемесячные_расходы ≥ 1
Fr = P_income / M_expenses ≥ 1
```

**Чистая стоимость:**
```
Чистая_стоимость = Активы - Обязательства
Net_worth = Assets - Liabilities
```

## 📈 Формулы инвестирования

**ROI (возврат инвестиций):**
```
ROI = (Прибыль - Инвестиции) / Инвестиции × 100%
ROI = (Gain - Investment) / Investment × 100%
```

**Правило 72:**
```
Время_удвоения ≈ 72 / Процент_годовых
T_double ≈ 72 / r
```

**Диверсификация:**
```
Риск_портфеля < ∑Риск_i
диверсификация снижает риск
```

**Риск и доходность:**
```
Доходность ∝ Риск
Return ∝ Risk
```

## 💡 Формулы успеха

**Успех:**
```
Успех = (Навыки × Усилия × Возможности) + Удача
S = (Sk × Ef × Op) + Lu
```

**Формула успеха Гладуэлла:**
```
Успех = 10,000 часов + Талант + Возможность
S = 10k_hours + Ta + Op
```

**Цена успеха:**
```
Успех = Жертвы + Время + Настойчивость
S = Sa + T + Pe
```

**Путь к вершине:**
```
Вершина = ∫(Усилия × Время) dt + Стратегия
Top = ∫(Ef × T) dt + St
```

## 📊 Экономические формулы

**Спрос и предложение:**
```
Цена = f(Спрос, Предложение)
P = f(D, S)
при D ↑, S const → P ↑
```

**Эластичность:**
```
E = (ΔQ/Q) / (ΔP/P)
чувствительность спроса к цене
```

**Стоимость денег во времени:**
```
PV = FV / (1 + r)^t
настоящая стоимость будущих денег
```

**Инфляция:**
```
Реальная_стоимость(t) = Номинал / (1 + i)^t
деньги обесцениваются
```

## 🎯 Формулы целей

**Достижение финансовой цели:**
```
Цель = (Накопления × Доходность) + Регулярные_взносы × Время
Go = (Sa × R) + C_regular × T
```

**SMART цели:**
```
Эффективность_цели = Конкретность × Измеримость × Достижимость × Релевантность × Сроки
Ef_goal = Sp × Me × Ac × Re × Ti
```

**Прогресс:**
```
Прогресс = Текущее / Целевое × 100%
Pr = Current / Target × 100%
```

## 💼 Бизнес-формулы

**Прибыль:**
```
Прибыль = Выручка - Затраты
Profit = Revenue - Costs
```

**Маржа:**
```
Маржа = (Выручка - Себестоимость) / Выручка × 100%
Margin = (Revenue - COGS) / Revenue × 100%
```

**Точка безубыточности:**
```
BEP = Постоянные_затраты / (Цена - Переменные_затраты_единицы)
```

**Масштабирование:**
```
Прибыль(n) = n × Прибыль_единицы - Постоянные_затраты
```

## 🧮 Формулы планирования

**Бюджет:**
```
Бюджет = Доходы ≥ Обязательные + Накопления + Свободные
Bu = I ≥ Es + Sa + Di
```

**Правило 50/30/20:**
```
Доходы = 50% Необходимое + 30% Желаемое + 20% Накопления
I = 50% Ne + 30% Wa + 20% Sa
```

**Подушка безопасности:**
```
Резерв = Ежемесячные_расходы × (3-6 месяцев)
Re = M_expenses × (3-6)
```

**Долг:**
```
Хороший_долг ≠ Плохой_долг
Good_debt ≠ Bad_debt
инвестиции vs потребление
```

## 📉 Формулы рисков

**Риск:**
```
Риск = Вероятность × Последствия
Ri = P × C
```

**Диверсификация портфеля:**
```
Риск_портфеля = √(∑∑ w_i × w_j × Cov(i,j))
```

**Страхование:**
```
Защита = Страховка × Покрытие / Премия
Pr = In × Co / Pr
```

**Максимальный убыток:**
```
Max_потеря = Капитал × Риск_%
не более 1-2% на сделку
```

## 🌟 Формулы богатства

**Путь к богатству:**
```
Богатство = (Доход - Расходы) × Время × (1 + Инвестиции)^Время
W = (I - E) × T × (1 + In)^T
```

**Пассивный доход:**
```
Пассив = Активы × Доходность
P_income = Assets × Yield
```

**Финансовая независимость:**
```
ФН = Капитал × 0.04 ≥ Годовые_расходы
FI = Capital × 0.04 ≥ Y_expenses
правило 4%
```

**Богатство vs Доход:**
```
Богатство ≠ Высокий_доход
Wealth ≠ High_income
богатство = активы, не зарплата
```

## 💳 Формулы долгов

**Общий долг:**
```
Долг_total = ∑(Кредит_i × (1 + r_i)^t_i)
```

**Долговая нагрузка:**
```
DTI = Платежи_по_долгам / Доход × 100%
DTI < 36% — здоровый уровень
```

**Эффект снежного кома:**
```
Погашение: Долг_min → Долг_max
сначала малые долги
```

**Кредитный рейтинг:**
```
Score = f(История, Использование, Возраст, Типы, Запросы)
```

## 🏆 Формулы конкурентного преимущества

**Конкурентное преимущество:**
```
Преимущество = Уникальность × Ценность / Цена
Ad = Un × Va / Pr
```

**Монополия:**
```
Прибыль_монопольная > Прибыль_конкурентная
конкурентов нет
```

**Барьеры входа:**
```
Защита = Барьеры_входа × Сетевые_эффекты
Pr = Entry_barriers × Network_effects
```

**Брендовая ценность:**
```
Бренд = Узнаваемость × Доверие × Лояльность
Br = Aw × Tr × Lo
```

## 📱 Современные формулы

**Стоимость привлечения клиента (CAC):**
```
CAC = Маркетинг + Продажи / Новые_клиенты
```

**Lifetime Value (LTV):**
```
LTV = Средний_чек × Частота × Срок_жизни
LTV = AV × Fr × Li
```

**Юнит-экономика:**
```
LTV / CAC ≥ 3
здоровый бизнес
```

**Вирусный коэффициент:**
```
K = Приглашения × Конверсия
K > 1 → экспоненциальный рост
```

## 🎓 Формулы человеческого капитала

**Человеческий капитал:**
```
HC = Образование + Опыт + Навыки + Здоровье
HC = Ed + Ex + Sk + He
```

**Стоимость времени:**
```
Цена_часа = Годовой_доход / 2000 часов
C_hour = Income_year / 2000h
```

**ROI образования:**
```
ROI_edu = (Доход_после - Доход_до - Стоимость_обучения) / Стоимость_обучения
```

**Навыки и доход:**
```
Доход ∝ Редкость_навыков × Спрос
I ∝ Rarity_skills × Demand
```

## 🔄 Формулы реинвестирования

**Компаунд-эффект:**
```
Результат(t) = Начальное × (1 + r)^t
Re(t) = Initial × (1 + r)^t
```

**Реинвестирование:**
```
Рост = Прибыль × Ставка_реинвестирования
Gr = Pr × Reinvestment_rate
```

**Снежный ком:**
```
Капитал(t) → Капитал(t) × e^(rt)
экспоненциальный рост
```

## 💎 Формулы ценности

**Воспринимаемая ценность:**
```
Ценность = Выгоды / Цена
Value = Benefits / Price
```

**Ценообразование:**
```
Цена = Себестоимость + Маржа
Price = Cost + Margin
```

**Ценовая дискриминация:**
```
Цена = f(Готовность_платить)
разные цены для разных клиентов
```

**Якорный эффект:**
```
Воспринимаемая_выгода = Якорь - Цена
Perceived_value = Anchor - Price
```

## 🌊 Формулы потоков

**Денежный поток:**
```
Кэш-флоу = Поступления - Выплаты
CF = Inflow - Outflow
```

**Операционный денежный поток:**
```
OCF = EBIT + Амортизация - Налоги - ΔWorking_Capital
```

**Свободный денежный поток:**
```
FCF = OCF - CapEx
```

**Дисконтированный денежный поток:**
```
DCF = ∑(CF_t / (1+r)^t)
```

## 🎰 Формулы удачи и риска

**Риск и награда:**
```
Ожидаемая_ценность = ∑(Вероятность_i × Исход_i)
EV = ∑(P_i × O_i)
```

**Правило Келли:**
```
f* = (bp - q) / b
оптимальная ставка
```

**Черный лебедь:**
```
P(событие) → 0, но Последствия → ∞
редкое, но критическое
```

**Антихрупкость:**
```
Антихрупкость: Выигрыш_от_волатильности > Потери_от_волатильности
```

## 🏃 Формулы скорости

**Скорость богатства:**
```
Скорость = (Ценность + Масштаб + Маржа) / Время
V = (Va + Sc + Ma) / T
```

**Быстрые деньги vs Медленные деньги:**
```
Быстрые: высокий риск, низкая устойчивость
Медленные: низкий риск, высокая устойчивость
```

**Временной горизонт:**
```
Краткосрочные ≠ Долгосрочные
Short_term ≠ Long_term
стратегии различны
```

## 🧠 Психология денег

**Деньги и счастье:**
```
Счастье = log(Деньги) при Деньги > Минимум
H = log(M) when M > Min
логарифмическая зависимость
```

**Относительное богатство:**
```
Ощущение_богатства = Твои_деньги / Деньги_окружения
Feeling_rich = Your_money / Others_money
```

**Жадность vs Страх:**
```
Решение = Жадность - Страх
Decision = Greed - Fear
эмоции влияют на финансы
```

**Потраченные деньги:**
```
Удовлетворение ≠ Сумма_траты
Satisfaction ≠ Amount_spent
впечатления > вещи
```

## 🌐 Глобальные формулы

**Неравенство (Джини):**
```
G = 0 (полное равенство) до 1 (полное неравенство)
```

**Правило Парето:**
```
80% богатства = 20% населения
```

**Глобализация:**
```
Возможности ∝ Связанность_с_миром
Op ∝ Global_connectivity
```
