FLOPS (Floating Point Operations Per Second) — производительность:
1 TFLOPS = 10^12 операций/сек
1 PFLOPS = 10^15 операций/сек (петафлопс)
1 EFLOPS = 10^18 операций/сек (эксафлопс)
1 ZFLOPS = 10^21 операций/сек (зеттафлопс, будущее)

TOP500 метрика:
• Ранжирование самых мощных суперкомпьютеров мира
• Benchmark: HPL (High Performance Linpack)
• Обновляется 2 раза в год (июнь, ноябрь)

Закон Амдала (параллелизм):
Speedup = 1 / (S + P/N)

где:
S — последовательная часть программы
P — параллельная часть
N — количество процессоров

→ Показывает: идеальный параллелизм недостижим

Энергоэффективность:
GFLOPS/Watt = Performance / Power_Consumption

→ Green500 ранжирует по энергоэффективности

Стоимость суперкомпьютера:
• Top-10: $100M - $500M
• Эксплуатация: $5M-20M/год (электричество, охлаждение, персонал)

Supercomputer = (Hardware × Architecture) × (Software × Applications) × (Infrastructure)

Компоненты:

Hardware (Железо):

Compute Nodes:
├─ CPUs:
│  ├─ Intel Xeon: традиционный выбор
│  ├─ AMD EPYC: растущая доля (лучшая цена/производительность)
│  ├─ ARM: энергоэффективные (Fugaku, Isambard)
│  └─ IBM POWER: специализированные HPC
├─ GPUs/Accelerators:
│  ├─ NVIDIA: A100, H100, H200 (доминируют в AI)
│  ├─ AMD Instinct: конкуренция NVIDIA
│  ├─ Intel Ponte Vecchio: новое направление
│  └─ Custom ASICs: Google TPU, Cerebras WSE
├─ Memory:
│  ├─ RAM: 256GB-2TB per node
│  ├─ HBM (High Bandwidth Memory): для GPUs
│  └─ NVMe SSD: локальное fast storage
└─ Количество:
   └─ Thousands-millions процессоров/ядер

Interconnect (Сеть):
├─ InfiniBand: высокая пропускная способность, низкая задержка
│  └─ HDR: 200 Gb/s per link
├─ Ethernet: 100-400 Gbps для некоторых систем
├─ Custom: Cray Slingshot, IBM POWER9 NVLink
└─ Topology:
   ├─ Fat tree: полная пропускная способность между узлами
   ├─ Dragonfly: масштабируемость
   └─ Torus: 3D/5D топология для balance

Storage:
├─ Parallel File Systems:
│  ├─ Lustre: open-source, распространён
│  ├─ GPFS (IBM Spectrum Scale): коммерческий
│  └─ BeeGFS: high-performance alternative
├─ Capacity: петабайты-экзабайты
├─ Bandwidth: TB/s aggregate
└─ Scratch vs Archive storage

Cooling (Охлаждение):
├─ Air cooling: традиционный
├─ Liquid cooling: прямой контакт с процессорами
│  └─ Более эффективный для dense systems
└─ Power Usage Effectiveness (PUE):
   └─ Цель: PUE < 1.1 (10% overhead)

Architecture (Архитектуры):

Cluster Computing:
├─ Много независимых узлов
├─ MPI (Message Passing Interface) для коммуникации
└─ Самая распространённая архитектура

MPP (Massively Parallel Processing):
├─ Tight coupling между узлами
└─ Cray systems традиционно

SMP (Symmetric Multiprocessing):
├─ Shared memory
└─ Limited scalability

Hybrid:
├─ CPU + GPU
└─ Heterogeneous computing (современный подход)

Software (ПО):

Operating System:
├─ Linux: доминирует (90%+ TOP500)
├─ Custom kernels: оптимизированные для HPC
└─ Container support: Docker, Singularity

Programming Models:
├─ MPI: distributed memory parallelism
├─ OpenMP: shared memory parallelism
├─ CUDA/HIP: GPU programming
├─ OpenCL: portable accelerator programming
└─ SHMEM, UPC: PGAS languages

Compilers:
├─ GCC, Clang: open-source
├─ Intel, NVIDIA HPC SDK: vendor-optimized
└─ Auto-vectorization, loop optimization

Libraries:
├─ BLAS, LAPACK: linear algebra
├─ FFTW: Fast Fourier Transform
├─ PETSc: partial differential equations
└─ cuDNN, TensorFlow, PyTorch: deep learning

Job Scheduling:
├─ Slurm: open-source, популярный
├─ PBS/Torque: классический
└─ LSF (IBM): коммерческий

Applications (Применения):

Scientific Computing:
├─ Climate modeling: IPCC reports
│  └─ Симуляции на десятилетия вперед
├─ Molecular dynamics: protein folding, drug design
│  └─ Миллионы атомов, микросекунды-миллисекунды
├─ Astrophysics: галактики, черные дыры
│  └─ N-body simulations, cosmology
├─ Quantum chemistry: электронная структура
│  └─ DFT, post-Hartree-Fock methods
└─ Materials science: новые материалы, катализаторы

Engineering:
├─ CFD (Computational Fluid Dynamics): аэродинамика
│  └─ Самолёты, автомобили, турбины
├─ Crash simulations: безопасность автомобилей
├─ Structural analysis: мосты, здания
└─ Reservoir simulation: нефтегаз

AI/ML:
├─ Training large language models: GPT, PaLM
│  └─ Weeks-months на тысячах GPUs
├─ Computer vision: ImageNet-scale datasets
├─ Reinforcement learning: AlphaGo, AlphaFold
└─ Recommendation systems: Netflix, Amazon

National Security:
├─ Nuclear weapons simulation: без ядерных испытаний
├─ Cryptography: breaking/designing codes
└─ Weather prediction: военные операции

Energy:
├─ Nuclear fusion: ITER simulations
├─ Battery design: электромобили
└─ Grid optimization: возобновляемые источники

Top Supercomputers (2024):

1. Frontier (USA, Oak Ridge):
   • 1.2 EFLOPS (эксафлопс!)
   • AMD EPYC + AMD Instinct GPUs
   • $600M стоимость
   • Первый exascale supercomputer

2. Aurora (USA, Argonne):
   • 1+ EFLOPS
   • Intel Xeon + Intel Ponte Vecchio GPUs
   • Долго задерживался, но наконец запущен

3. Fugaku (Japan, RIKEN):
   • 442 PFLOPS
   • ARM processors (Fujitsu A64FX)
   • Энергоэффективный
   • COVID-19 research hero

4. Sunway TaihuLight (China, Wuxi):
   • 93 PFLOPS
   • Custom Chinese processors
   • Демонстрация независимости от US tech

5. Summit (USA, Oak Ridge):
   • 200 PFLOPS
   • IBM POWER9 + NVIDIA V100
   • Предшественник Frontier

Trends:
• Exascale достигнут (Frontier)
• GPU acceleration доминирует
• Energy efficiency критична
• China-US competition

Challenges (Вызовы):

Technical:
├─ Power consumption: exascale = 20-30 MW
│  └─ Эквивалент ~20,000 домов
├─ Cooling: тепловыделение огромно
├─ Reliability: миллионы компонентов → failures частые
│  └─ MTBF часы-дни
├─ Programming: параллелизм сложен
│  └─ Amdahl's Law limits
└─ I/O bottleneck: storage не успевает за compute

Economic:
├─ Cost: $100M-$500M капитальные затраты
├─ Operations: $5M-20M/год
├─ Rapid obsolescence: 5-7 лет lifecycle
└─ ROI: научная ценность vs стоимость

Geopolitical:
├─ US-China rivalry: престиж, национальная безопасность
├─ Export controls: US ограничивает продажи в Китай
│  └─ GPUs, EDA tools, semiconductors
└─ Semiconductor independence: China инвестирует триллионы

Environmental:
├─ Carbon footprint: электричество = CO2
├─ E-waste: короткий lifecycle
└─ Water usage: охлаждение

ОБЪЯСНЕНИЕ:

ИСТОРИЯ:

1940s-50s: ENIAC, первые компьютеры
• Артиллерийские таблицы, ядерные расчёты
• Холодная война → compute = стратегическое преимущество

1960s-80s: Cray Era
• Seymour Cray — "отец суперкомпьютеров"
• Cray-1 (1976): 160 MFLOPS
• Применение: ядерное оружие, криптография, погода

1990s-2000s: Cluster Computing
• Beowulf clusters: commodity hardware
• Linux доминирует
• Democratization of HPC

2010s: GPU Acceleration
• NVIDIA CUDA → scientific computing
• Deep learning revolution
• AI training на суперкомпьютерах

2020s: Exascale Era
• Frontier (2022): первый exaflop
• China-US rivalry обостряется
• AI compute — новая нефть

ПРАКТИЧЕСКИЕ РЕКОМЕНДАЦИИ:

1. ДЛЯ ИССЛЕДОВАТЕЛЕЙ:

   Доступ:
   • XSEDE (USA): бесплатный compute для академии
   • EuroHPC: европейские ресурсы
   • National labs: competitive proposals
   
   Оптимизация:
   • Profile first: где bottlenecks?
   • Vectorization: SIMD instructions
   • MPI: scale to thousands of cores
   • GPU porting: 10-100x speedup
   
   Best practices:
   • Checkpointing: save state (failures happen!)
   • Efficient I/O: bottleneck для многих
   • Queue etiquette: не waste resources

2. ДЛЯ КОМПАНИЙ:

   Cloud HPC:
   • AWS, Azure, GCP: on-demand supercomputing
   • Pay-per-use: избегаете capex
   • Scalability: от десятков до тысяч nodes
   
   On-prem vs Cloud:
   • On-prem: control, security, long-term cheaper
   • Cloud: flexibility, no maintenance, fast start
   
   ROI:
   • Faster time-to-market: simulations vs physical prototypes
   • Cost savings: virtual testing
   • Innovation: problems impossible before

3. ДЛЯ СТРАН:

   Strategic investment:
   • Суперкомпьютеры = infrastructure
   • R&D funding: долгосрочная перспектива
   • Education: HPC workforce training
   
   Independence:
   • Domestic semiconductor industry
   • Software stack: avoid vendor lock-in
   • International collaboration: vs isolationism
   
   Sustainability:
   • Renewable energy: power datacenters
   • Waste heat reuse: district heating
   • Lifecycle planning: e-waste management
