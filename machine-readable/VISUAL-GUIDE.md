## 🎯 СЦЕНАРИИ ИСПОЛЬЗОВАНИЯ

### Сценарий 1: Прямая интеграция с GPT-4

```
User Question
     │
     ▼
┌─────────────┐
│ RAG Agent   │ ← Извлечь контекст из базы знаний
└─────┬───────┘
      │ context
      ▼
┌─────────────┐
│   GPT-4     │ ← Генерировать ответ на основе контекста
└─────┬───────┘
      │ response
      ▼
    User
```

### Сценарий 2: Autonomous Q&A

```
User Question
     │
     ▼
┌─────────────┐
│ RAG Agent   │ ← Автономно принимает решение
└─────┬───────┘
      │
      ├─ IF confidence > 0.85 → Прямой ответ
      │
      ├─ IF confidence > 0.60 → Несколько вариантов
      │
      ├─ IF confidence > 0.30 → Расширить поиск + LLM
      │
      └─ ELSE → Попросить уточнить вопрос
```

### Сценарий 3: Чатбот с памятью

```
User: "Что такое blockchain?"
  ↓
Agent: Находит в базе [level 1] формулу + [level 4] примеры
  ↓
User: "Приведи ещё примеры"
  ↓
Agent: Знает контекст → ищет только [level 4] примеры
```
