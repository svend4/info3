# Здоровье — Формулы здорового образа жизни

## 💪 Базовые формулы здоровья

**Общее здоровье:**
```
Здоровье = Физическое + Психическое + Социальное
H = Ph + Me + So
определение ВОЗ
```

**Энергия:**
```
Энергия = Сон + Питание + Движение - Стресс
E = Sl + Fo + Ex - St
```

**Продолжительность жизни:**
```
Долголетие = Генетика × (Образ_жизни + Среда + Медицина)
Lo = Ge × (Li + En + Me)
```

**Качество жизни:**
```
QoL = (Здоровье + Функциональность) / Болезни
QoL = (He + Fu) / Di
```

## 🏃 Формулы физической активности

**Калории:**
```
Баланс = Калории_потреблённые - Калории_сожжённые
Ba = C_in - C_out
```

**Вес:**
```
Вес(t) = Вес(0) + (Калории_избыток / 7700) кг
7700 ккал ≈ 1 кг жира
```

**ИМТ (индекс массы тела):**
```
ИМТ = Вес(кг) / Рост(м)²
BMI = Weight / Height²
18.5-24.9 — норма
```

**Частота пульса:**
```
Макс_пульс ≈ 220 - Возраст
Max_HR ≈ 220 - Age
```

**Целевая зона пульса:**
```
Зона = (Макс_пульс - Пульс_покоя) × Интенсивность + Пульс_покоя
Zone = (Max_HR - Rest_HR) × Intensity + Rest_HR
```

## 🥗 Формулы питания

**Сбалансированное питание:**
```
Питание = Белки + Жиры + Углеводы + Витамины + Минералы + Вода
Fo = Pr + Fa + Ca + Vi + Mi + Wa
```

**Макронутриенты:**
```
Калории = Белки×4 + Углеводы×4 + Жиры×9
C = P×4 + C×4 + F×9
```

**Потребность в калориях:**
```
TDEE = BMR × Коэффициент_активности
BMR (мужчины) = 10×Вес + 6.25×Рост - 5×Возраст + 5
BMR (женщины) = 10×Вес + 6.25×Рост - 5×Возраст - 161
```

**Вода:**
```
Норма_воды ≈ Вес(кг) × 30-40 мл/день
Water ≈ Weight × 30-40 ml/day
```

## 😴 Формулы сна

**Качество сна:**
```
Качество = (Глубокий_сон + REM) / Общее_время
Q = (Deep + REM) / Total
```

**Потребность во сне:**
```
Сон_оптимальный = 7-9 часов для взрослых
Sleep_optimal = 7-9h for adults
```

**Недосып:**
```
Долг_сна = ∑(Норма - Фактический)
накапливается
```

**Циркадные ритмы:**
```
Энергия(t) = sin(2πt/24) + Базовая
циклы 24 часа
```

## 🧘 Формулы стресса

**Стресс:**
```
Стресс = Требования / Ресурсы
S = De / Re
```

**Аллостатическая нагрузка:**
```
Износ = ∫(Стресс × Время) dt
AL = ∫(S × T) dt
хронический стресс разрушает
```

**Восстановление:**
```
Восстановление = Отдых + Сон + Релаксация
Re = Rest + Sleep + Rel
```

**Кортизол:**
```
Кортизол ∝ Стресс
избыток кортизола вреден
```

## 🧬 Формулы старения

**Биологический возраст:**
```
Биологический ≠ Хронологический
Biological ≠ Chronological
```

**Теломеры:**
```
Длина_теломер(t) = Длина(0) - k×t + Образ_жизни
укорачиваются с возрастом
```

**Старение:**
```
Старение = Окислительный_стресс + Воспаление + Гликация
Aging = OS + In + Gl
```

**Антистарение:**
```
Молодость = Антиоксиданты + Упражнения + Калорийное_ограничение
Youth = AO + Ex + CR
```

## 💊 Формулы профилактики

**Профилактика > Лечение:**
```
Профилактика << Лечение (по стоимости)
Prevention << Treatment (cost)
но Профилактика >> Лечение (по эффекту)
```

**Иммунитет:**
```
Иммунитет = Питание + Сон + Активность - Стресс
Im = Fo + Sl + Ac - St
```

**Риск болезни:**
```
Риск = Генетика × Образ_жизни × Среда
Ri = Ge × Li × En
```

**Скрининг:**
```
Эффективность = Ранняя_диагностика / Стоимость
Ef = Early_detection / Cost
```

## 🏥 Формулы лечения

**Выздоровление:**
```
Исцеление = Лечение + Время + Организм
He = Tr + T + Bo
```

**Эффективность лекарства:**
```
Эффект = Доза × Биодоступность - Побочные_эффекты
Ef = Do × Bi - Side
```

**Плацебо:**
```
Эффект_плацебо = Ожидание × Внушение
Pl_effect = Ex × Su
может быть 30-40%
```

**Доза-ответ:**
```
Эффект = f(Доза)
малые дозы → нет эффекта
большие дозы → токсичность
```

## 🧠 Формулы психического здоровья

**Ментальное здоровье:**
```
МЗ = Эмоциональное + Когнитивное + Социальное
MH = Em + Co + So
```

**Благополучие:**
```
Благополучие = Позитив - Негатив + Смысл
WB = Po - Ne + Me
```

**Депрессия:**
```
Риск_депрессии = (Стресс + Изоляция) / (Поддержка + Активность)
Ri_depression = (St + Is) / (Su + Ac)
```

**Тревога:**
```
Тревога = Угроза × Неопределённость / Контроль
An = Th × Un / Co
```

## 💓 Формулы сердечно-сосудистой системы

**Давление:**
```
АД = Систолическое / Диастолическое
BP = Systolic / Diastolic
120/80 — норма
```

**Сердечный риск:**
```
Риск = Холестерин + Давление + Курение + Диабет + Возраст
Ri = Ch + BP + Sm + Di + Ag
```

**VO2 max:**
```
Аэробная_выносливость = Максимальное_потребление_O2
кардио-фитнес
```

**Сердечный выброс:**
```
CO = Ударный_объём × ЧСС
Cardiac_output = Stroke_volume × Heart_rate
```

## 🦴 Формулы костно-мышечной системы

**Мышечная масса:**
```
Мышцы = Тренировки × Питание (белок) × Отдых
Mu = Tr × Pr × Re
```

**Сила:**
```
Сила = Мышечная_масса × Нейронная_адаптация
St = Mu × Ne
```

**Плотность костей:**
```
Кости = Кальций + Витамин_D + Нагрузка
Bo = Ca + VitD + Lo
```

**Гибкость:**
```
Гибкость = Растяжка × Регулярность / Возраст
Fl = St × Re / Ag
```

## 🦠 Формулы инфекций

**Распространение:**
```
R0 = Базовое_число_репродукции
R0 > 1 → эпидемия
R0 < 1 → затухание
```

**Иммунный ответ:**
```
Ответ = Антитела + Т-клетки + Память
Re = Ab + T_cells + Me
```

**Вакцинация:**
```
Коллективный_иммунитет = 1 - 1/R0
порог для защиты популяции
```

**Антибиотики:**
```
Эффективность ∝ 1/Резистентность
избыточное использование → резистентность
```

## 🧬 Формулы генетики

**Генетический риск:**
```
Риск = Наследственность × Проявление
Ri = He × Pe
гены + среда
```

**Эпигенетика:**
```
Экспрессия_гена = f(Ген, Образ_жизни)
G_expression = f(Gene, Lifestyle)
гены можно включать/выключать
```

**Наследуемость:**
```
h² = Генетическая_вариация / Общая_вариация
```

## 🏋️ Формулы тренировок

**Принцип перегрузки:**
```
Адаптация = Стимул > Привычная_нагрузка
Ad = St > Habitual_load
```

**Восстановление:**
```
Время_восстановления ∝ Интенсивность × Объём
Re_time ∝ In × Vo
```

**Прогрессивная перегрузка:**
```
Нагрузка(t+1) = Нагрузка(t) × (1 + k)
постепенное увеличение
```

**Суперкомпенсация:**
```
Форма(t) = sin(t) + Тренд_вверх
циклы нагрузка-восстановление-рост
```

## 🧪 Формулы биохимии

**Метаболизм:**
```
Метаболизм = Анаболизм + Катаболизм
Me = Ana + Cata
построение и разрушение
```

**Гликемический индекс:**
```
ГИ = Уровень_глюкозы / Уровень_эталона × 100
высокий ГИ → быстрый всплеск сахара
```

**Гормональный баланс:**
```
Баланс = Гормоны_анаболические / Гормоны_катаболические
тестостерон/кортизол
```

**pH крови:**
```
pH = 7.35-7.45
отклонение → ацидоз/алкалоз
```

## 🌿 Формулы естественного здоровья

**Природа и здоровье:**
```
Здоровье ∝ Время_на_природе
Nature ∝ Health
```

**Солнечный свет:**
```
Витамин_D = f(УФ-излучение × Время × Площадь_кожи)
15-30 минут в день
```

**Микробиом:**
```
Здоровье_кишечника = Разнообразие_бактерий × Баланс
Gut_health = Diversity × Balance
```

**Дыхание:**
```
Оксигенация = Глубина × Частота
Deep_breathing → Релаксация
```

## 📊 Формулы измерения здоровья

**Биомаркеры:**
```
Здоровье = f(Глюкоза, Холестерин, Давление, Воспаление, ...)
H = f(Glucose, Cholesterol, BP, Inflammation, ...)
```

**Функциональный возраст:**
```
Функц_возраст = Тесты_физические + Когнитивные
Func_age = Physical_tests + Cognitive
```

**Отслеживание:**
```
Улучшение = Измерение + Обратная_связь + Действие
Im = Me + Fe + Ac
```

## 🔄 Формулы образа жизни

**Здоровый образ жизни:**
```
ЗОЖ = Питание + Движение + Сон + Стресс↓ + Соц.связи
HLS = Fo + Ex + Sl + St↓ + So
```

**Привычки:**
```
Здоровье(t) = ∑(Привычки_ежедневные)^t
долгосрочный эффект
```

**Баланс:**
```
Баланс = Работа / Отдых ≈ 1
Ba = Wo / Re ≈ 1
```

**Гомеостаз:**
```
Стабильность = Адаптация × Регуляция
Ho = Ad × Re
организм стремится к равновесию
```
