Moore's Law (Закон Мура):
N(t) = N₀ × 2^(t/k)

где:
N(t) — количество транзисторов на чипе в момент времени t
N₀ — начальное количество транзисторов
k — период удвоения (исторически ~2 года)
t — время

Dennard Scaling (до ~2006):
P ∝ V² × f

где:
P — энергопотребление
V — напряжение
f — частота

→ При уменьшении размера транзисторов, можно увеличить частоту 
  без роста энергопотребления

Process Node (технологический процесс):
Density ∝ 1 / (feature_size)²

→ 7nm процесс = в 4 раза плотнее 14nm процесса

Performance per Watt:
Efficiency = FLOPS / Watt

→ Ключевая метрика для мобильных устройств и datacenters

Chip = (Design × Lithography) × (Materials × Packaging) × (Testing × Yield)

Компоненты:

Design (Проектирование):
├─ Architecture: ISA (x86, ARM, RISC-V)
├─ Logic design: цифровая логика, state machines
├─ Circuit design: транзисторный уровень
├─ Physical design: layout, place & route
├─ Verification: симуляция, formal verification
└─ EDA tools: Cadence, Synopsys, Mentor Graphics

Lithography (Литография):
├─ Photomask: шаблон для печати на кремнии
├─ EUV (Extreme Ultraviolet): 13.5nm длина волны
├─ Steppers: ASML (монополия на EUV оборудование)
├─ Resolution: 3nm, 5nm, 7nm (современные процессы)
└─ Multi-patterning: несколько проходов для мелких деталей

Materials (Материалы):
├─ Silicon wafers: 300mm диаметр (12 inch)
├─ Doping: добавление примесей (P, N типы)
├─ Metals: медь для проводников, алюминий
├─ Dielectrics: изоляторы между слоями
├─ High-k metal gate: уменьшение утечек тока
└─ FinFET: 3D транзисторы (вместо planar)

Packaging (Корпусирование):
├─ Die cutting: разрезание wafer на чипы
├─ Wire bonding: соединение чипа с package
├─ Flip chip: прямое соединение bumps
├─ 2.5D/3D stacking: чипы друг на друге
└─ Thermal management: отвод тепла

Testing & Yield (Тестирование):
├─ Wafer testing: проверка каждого die
├─ Binning: сортировка по характеристикам
├─ Yield: процент рабочих чипов (70-95%)
└─ Failure analysis: почему чипы не работают

Типы чипов:

1. CPU (Central Processing Unit):
   ├─ x86: Intel (Core), AMD (Ryzen, EPYC)
   ├─ ARM: Apple M-series, Qualcomm, MediaTek
   └─ RISC-V: открытая архитектура, растущее применение

2. GPU (Graphics Processing Unit):
   ├─ NVIDIA: GeForce, RTX (gaming), A100/H100 (AI)
   ├─ AMD: Radeon (gaming), Instinct (datacenter)
   └─ Intel: Arc (новое направление)

3. ASIC (Application-Specific IC):
   ├─ Bitcoin miners: оптимизированы для SHA-256
   ├─ TPU (Google): Tensor Processing Unit для AI
   └─ Network processors: роутеры, коммутаторы

4. FPGA (Field-Programmable Gate Array):
   ├─ Xilinx (AMD), Intel Altera
   ├─ Перепрограммируемая логика
   └─ Применение: прототипирование, специализированные задачи

5. Memory:
   ├─ DRAM: Samsung, SK Hynix, Micron
   ├─ NAND Flash: SSD, USB drives
   └─ HBM (High Bandwidth Memory): для GPU

6. SoC (System on Chip):
   ├─ Смартфоны: Snapdragon, Apple A-series
   ├─ Интеграция: CPU + GPU + NPU + modem
   └─ Power efficiency: критично для батареи

Технологические узлы (Process Nodes):

История:
180nm (1999) → 130nm (2001) → 90nm (2004) → 65nm (2006) 
→ 45nm (2008) → 32nm (2010) → 22nm (2012) → 14nm (2014) 
→ 10nm (2017) → 7nm (2018) → 5nm (2020) → 3nm (2022)

Лидеры:
├─ TSMC (Taiwan): 55% рынка foundry, самые передовые процессы (3nm, 2nm в разработке)
├─ Samsung: 15% рынка, конкурирует с TSMC
├─ Intel: переход на foundry модель, планы на 18A (1.8nm)
└─ SMIC (China): отстаёт на ~3 поколения из-за санкций

Стоимость fab (фабрики):
├─ 28nm fab: $3-5 млрд
├─ 7nm fab: $10-15 млрд
├─ 3nm fab: $15-20 млрд
└─ 2nm fab (планируется): $20-30 млрд

ОБЪЯСНЕНИЕ:

1965: Гордон Мур (Intel) предсказал удвоение количества транзисторов 
на чипе каждые 2 года.

ЭТО НЕ ЗАКОН ПРИРОДЫ, а наблюдение + индустриальная цель:
• Компании инвестировали миллиарды, чтобы соответствовать прогнозу
• Self-fulfilling prophecy: все ожидали этого, поэтому это происходило
• Конкуренция: отставание = смерть компании

НО СЕЙЧАС (2024):
Закон Мура замедляется и, возможно, заканчивается.

Полупроводники — основа современной цивилизации и стратегический ресурс XXI века.
