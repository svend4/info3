Научный метод:
Observation → Hypothesis → Experiment → Analysis → Conclusion

Цикл повторяется: Conclusion → New Hypothesis

Knowledge Growth = f(Research × Collaboration × Verification)

Экспоненциальный рост:
Publications_per_year ∝ e^(kt)

где k ≈ 0.05 (удвоение каждые 14 лет)

Информационный взрыв:
• 1665: 1 научный журнал (Philosophical Transactions)
• 2024: ~30,000 peer-reviewed journals
• ~3 million научных статей публикуется в год

Проблема: никто не может прочитать даже малую часть

Закон Парето в науке (80/20):
• 20% учёных производят 80% открытий
• 20% статей получают 80% цитирований
• 50% статей никогда не цитируются

h-index (влиятельность учёного):
h = максимальное число статей с ≥h цитированиями

Пример: h-index 50 = 50 статей с ≥50 цитированиями каждая

Science = (Method × Ethics) × (Communication × Collaboration) × (Technology)

Компоненты:

Scientific Method (Научный метод):
├─ Observation: наблюдение явления
├─ Question: формулировка вопроса
├─ Hypothesis: предположение о механизме
├─ Prediction: что произойдёт, если гипотеза верна
├─ Experiment: проверка предсказания
├─ Analysis: статистика, интерпретация
└─ Conclusion: подтверждение/отклонение гипотезы

Типы исследований:
├─ Basic research: фундаментальные знания (почему небо голубое?)
├─ Applied research: практические применения (как сделать лучший солнечный элемент?)
├─ Translational research: от лаборатории к клинике
└─ Industrial R&D: разработка продуктов

Disciplines (Дисциплины):
├─ Natural Sciences:
│  ├─ Physics: материя, энергия, силы
│  ├─ Chemistry: вещества, реакции
│  ├─ Biology: жизнь, эволюция
│  ├─ Earth Science: геология, климат
│  └─ Astronomy: космос, звёзды, галактики
├─ Formal Sciences:
│  ├─ Mathematics: абстрактные структуры
│  ├─ Logic: рассуждения
│  ├─ Statistics: анализ данных
│  └─ Computer Science: вычисления, алгоритмы
├─ Social Sciences:
│  ├─ Psychology: разум, поведение
│  ├─ Sociology: общество, культура
│  ├─ Economics: рынки, ресурсы
│  └─ Political Science: власть, управление
└─ Applied Sciences:
   ├─ Medicine: здоровье, лечение
   ├─ Engineering: дизайн, строительство
   └─ Agriculture: производство пищи

Research Process:
├─ Literature Review: что уже известно?
├─ Grant Writing: финансирование исследования
├─ Experimental Design: планирование эксперимента
├─ Data Collection: сбор данных
├─ Analysis: статистика, моделирование
├─ Writing: статья для журнала
├─ Peer Review: оценка коллегами
└─ Publication: распространение знаний

Peer Review:
├─ Submission: автор отправляет статью в журнал
├─ Editor screening: редактор проверяет релевантность
├─ Reviewer assignment: 2-3 эксперта для оценки
├─ Reviews: критика методов, выводов
├─ Decision:
│  ├─ Accept: публикация (редко сразу)
│  ├─ Minor revisions: небольшие правки
│  ├─ Major revisions: существенные изменения
│  └─ Reject: не подходит для журнала
└─ Revision cycle: может повториться несколько раз

Impact Factor:
IF = Citations_to_recent_articles / Number_of_recent_articles

→ Метрика престижности журнала
→ Nature: IF ~50, Science: ~45
→ Критика: gaming the system, не отражает качество отдельной статьи

Open Science Movement:
├─ Open Access: статьи доступны бесплатно
│  ├─ Gold OA: журнал полностью open (автор платит APC)
│  ├─ Green OA: самоархивирование (preprints)
│  └─ Diamond OA: бесплатно для всех (редко)
├─ Open Data: данные доступны для проверки
├─ Open Source: код и методы публикуются
├─ Preregistration: гипотезы до эксперимента (против p-hacking)
└─ Replication: повторение исследований

Reproducibility Crisis:
• Psychology: 39% исследований воспроизводятся
• Cancer biology: 11% воспроизводятся
• Причины:
  ├─ P-hacking: манипуляция данных для значимости
  ├─ HARKing: Hypothesizing After Results are Known
  ├─ Publication bias: позитивные результаты публикуются чаще
  ├─ Small sample sizes: недостаточная статистическая мощность
  └─ Poor documentation: методы не полностью описаны

Technology в науке:
├─ Computation:
│  ├─ Simulations: climate models, drug design
│  ├─ Data analysis: statistics, ML
│  └─ Visualization: понимание сложных данных
├─ Instrumentation:
│  ├─ Microscopes: от optical до electron до atomic force
│  ├─ Telescopes: от optical до radio до space-based
│  ├─ Particle accelerators: LHC, CERN
│  └─ Sequencers: геномика, proteomics
├─ AI/ML:
│  ├─ Hypothesis generation: анализ литературы
│  ├─ Experiment design: оптимизация параметров
│  ├─ Data analysis: pattern recognition
│  └─ Discovery: AlphaFold (protein folding), материаловедение
└─ Collaboration tools:
   ├─ GitHub: код, данные
   ├─ Slack/Discord: общение команды
   └─ Jupyter notebooks: reproducible research

Funding:
├─ Government:
│  ├─ NSF (USA): National Science Foundation
│  ├─ NIH (USA): National Institutes of Health
│  ├─ ERC (Europe): European Research Council
│  └─ Competitive grants: proposal writing
├─ Private:
│  ├─ Foundations: Gates, Wellcome Trust
│  ├─ Industry: pharma, tech companies
│  └─ Crowdfunding: редко, но растёт
└─ University: internal grants, startup packages

Ethics:
├─ Research integrity:
│  ├─ Honesty: no fabrication, falsification
│  ├─ Objectivity: avoid bias
│  └─ Attribution: proper citation, no plagiarism
├─ Conflicts of interest: disclosure of funding sources
├─ Research subjects:
│  ├─ Informed consent: participants understand risks
│  ├─ Privacy: confidentiality of data
│  └─ IRB/Ethics board approval
├─ Animal research: minimize suffering, 3Rs (Replace, Reduce, Refine)
└─ Dual use: research with potential military/harmful applications

ОБЪЯСНЕНИЕ:

НАУКА — НЕ КОЛЛЕКЦИЯ ФАКТОВ, А ПРОЦЕСС

Популярное заблуждение: "Наука доказала X"
Реальность: "Текущие данные поддерживают X с confidence level 95%"

Наука никогда не "доказывает" в абсолютном смысле (это математика).
Наука accumulates evidence, которое делает теорию более/менее вероятной.

САМОКОРРЕКЦИЯ:

Примеры исправления ошибок:
• Флогистон → Кислород (XVIII век)
• Эфир → Специальная теория относительности
• Статичная вселенная → Расширяющаяся (Hubble)
• Язвы от стресса → H. pylori бактерия (Nobel Prize 2005)

НО: коррекция может занять десятилетия
• Континентальный дрейф (Wegener, 1912) → принят в 1960s
• Прионы (Prusiner) → скептицизм годами, Nobel 1997

ПРОБЛЕМЫ СОВРЕМЕННОЙ НАУКИ:

1. REPRODUCIBILITY CRISIS:
   • Psychology: 39% воспроизводятся
   • Preclinical cancer research: 11%
   • Причины: small samples, p-hacking, publication bias

2. PUBLISH OR PERISH:
   • Давление публиковаться → quantity over quality
   • Incentive misalignment: novel > replication
   • Negative results не публикуются (file drawer effect)

3. HYPED MEDIA COVERAGE:
   • "Breakthrough!" каждую неделю
   • Preliminary results → definitive claims
   • Nuance теряется в headlines

4. PREDATORY JOURNALS:
   • Pay-to-publish без peer review
   • Загрязнение литературы junk science

5. SILOS:
   • Узкая специализация → потеря big picture
   • Междисциплинарность сложна (разные языки, методы)

КОНСЕНСУС ФОРМИРУЕТСЯ МЕДЛЕННО:

Процесс:
1. Новое открытие → скептицизм
2. Репликации → подтверждение или опровержение
3. Механизм → понимание "почему"
4. Метаанализ → количественная оценка эффекта
5. Консенсус → учебники, clinical practice

Время: 10-30 лет от открытия до консенсуса

ХОРОШИЕ НОВОСТИ:

Несмотря на проблемы, наука работает:
• Вакцины: полиомиелит, корь, COVID-19
• Антибиотики: увеличили продолжительность жизни
• Green Revolution: накормили миллиарды
• Интернет, компьютеры, GPS: от физики к технологии
• Climate science: consensus по антропогенному изменению

Ключ: weight of evidence
• Одно исследование ≠ доказательство
• Meta-analysis > single study
• Replication укрепляет уверенность

ЗАКЛЮЧЕНИЕ:

Наука — лучший метод познания мира, который у нас есть.
Не совершенный, но самокорректирующийся.

Ключевые принципы:
• Скептицизм: требуйте доказательств
• Воспроизводимость: результаты должны повторяться
• Открытость: методы и данные доступны
• Самокоррекция: ошибки исправляются

"Наука знает, что не знает всего, иначе она бы остановилась"

Доверие к науке ≠ слепая вера
Доверие к науке = понимание процесса и его ограничений
