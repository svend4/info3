# Природа и экология — Формулы окружающей среды

## 🌍 Базовые формулы природы

**Экосистема:**
```
Экосистема = Биотические_факторы + Абиотические_факторы
Ec = Bi_factors + Ab_factors
```

**Баланс природы:**
```
Баланс = Производство = Потребление = Разложение
Ba = Production = Consumption = Decomposition
```

**Биоразнообразие:**
```
Устойчивость ∝ Разнообразие
Re ∝ Diversity
больше видов = стабильнее
```

**Гомеостаз:**
```
Стабильность = Обратные_связи × Адаптация
St = Feedbacks × Adaptation
```

## 🔄 Формулы циклов

**Круговорот воды:**
```
Вода = Испарение → Конденсация → Осадки → Сток
Wa = Evaporation → Condensation → Precipitation → Runoff
```

**Углеродный цикл:**
```
CO₂: Атмосфера ⇔ Растения ⇔ Животные ⇔ Почва ⇔ Океаны
```

**Азотный цикл:**
```
N₂ → Фиксация → NH₃ → NO₃ → Денитрификация → N₂
```

**Энергетический поток:**
```
Солнце → Растения → Травоядные → Хищники → Разложение
однонаправленный
```

## 🌱 Формулы роста

**Фотосинтез:**
```
6CO₂ + 6H₂O + свет → C₆H₁₂O₆ + 6O₂
```

**Рост популяции:**
```
dN/dt = rN(1 - N/K)
логистический рост
K — ёмкость среды
```

**Биомасса:**
```
Биомасса = Продукция - Дыхание - Отмирание
Bi = Pr - Re - De
```

**Сукцессия:**
```
Экосистема: Пионеры → Переходные → Климакс
```

## ⚖️ Формулы баланса

**Устойчивое развитие:**
```
Устойчивость = Экономика ∩ Социум ∩ Экология
Su = Economy ∩ Society ∩ Ecology
тройной баланс
```

**Потребление:**
```
Потребление ≤ Возобновление
Co ≤ Renewal
```

**Экологический след:**
```
След = Потребление / Биоёмкость
Fo = Consumption / Biocapacity
```

**Дефицит:**
```
Дефицит = Спрос - Предложение_природы
De = Demand - Nature_supply
```

## 🏭 Формулы загрязнения

**Загрязнение:**
```
Загрязнение = Выбросы - Поглощение_природой
Po = Emissions - Nature_absorption
```

**Кумулятивный эффект:**
```
Загрязнение(t) = ∫(Выбросы - Очистка) dt
Po(t) = ∫(Em - Cl) dt
```

**Разложение:**
```
Концентрация(t) = Концентрация(0) × e^(-kt)
где k — скорость разложения
```

**Биоаккумуляция:**
```
Концентрация_в_организме ∝ Уровень_трофический
```

## 🌡️ Формулы климата

**Парниковый эффект:**
```
Температура ∝ [CO₂] + [CH₄] + [N₂O]
Te ∝ [CO₂] + [CH₄] + [N₂O]
```

**Глобальное потепление:**
```
ΔT = λ × ΔF
где λ — чувствительность климата
ΔF — радиационное воздействие
```

**Альбедо:**
```
Отражение = Альбедо × Падающий_свет
Re = Albedo × Incident_light
```

**Петля обратной связи:**
```
Потепление → Таяние_льда → ↓Альбедо → Потепление↑
положительная обратная связь
```

## 🦁 Формулы взаимодействий

**Хищник-жертва (Лотка-Вольтерра):**
```
dN/dt = rN - aNP
dP/dt = baNP - mP
циклические колебания
```

**Конкуренция:**
```
dN₁/dt = r₁N₁(K₁ - N₁ - αN₂)/K₁
конкуренция за ресурсы
```

**Симбиоз:**
```
Взаимная_выгода: A + B → A+ + B+
```

**Паразитизм:**
```
A + B → A+ + B−
один выигрывает, другой проигрывает
```

## 💧 Формулы воды

**Доступность воды:**
```
Вода_пресная = Осадки - Испарение - Сток
Fr_water = Pr - Ev - Ru
```

**Качество воды:**
```
Качество = 1 / Загрязнение
Q = 1 / Pollution
```

**Водный след:**
```
След = Прямое_потребление + Виртуальная_вода
Fo = Direct_use + Virtual_water
```

**Дефицит воды:**
```
Стресс = Потребление / Доступность > 0.4
St = Use / Availability > 0.4
```

## 🌳 Формулы лесов

**Леса:**
```
Леса = Фотосинтез + Биоразнообразие + Углерод + Кислород
Fo = Ph + Bi + C + O₂
```

**Обезлесение:**
```
Потеря = Вырубка + Пожары - Восстановление
Lo = De + Fi - Re
```

**Секвестрация углерода:**
```
Углерод_связанный = Биомасса × k_углерода
C_sequestered = Biomass × k_carbon
```

**Экосистемные услуги:**
```
Ценность = Кислород + Вода + Климат + Биоразнообразие
Va = O₂ + Wa + Cl + Bi
```

## 🐝 Формулы опыления

**Опыление:**
```
Урожай ∝ Опылители × Растения
Yi ∝ Pollinators × Plants
```

**Коллапс колоний:**
```
Гибель_пчёл = Пестициды + Болезни + Потеря_среды
Be_decline = Pe + Di + Ha_loss
```

**Биоразнообразие опылителей:**
```
Устойчивость ∝ Разнообразие_опылителей
Re ∝ Pollinator_diversity
```

## 🌊 Формулы океанов

**Закисление океанов:**
```
pH_океана = f([CO₂]_атмосфера)
pH ↓ при CO₂ ↑
```

**Рыбные запасы:**
```
Популяция(t+1) = Популяция(t) + Размножение - Вылов
Po(t+1) = Po(t) + Re - Fi
```

**Перелов:**
```
Перелов = Вылов > MSY
Overfishing = Catch > Maximum_Sustainable_Yield
```

**Коралловые рифы:**
```
Здоровье = 1 / (Температура + Закисление + Загрязнение)
He = 1 / (Te + Ac + Po)
```

## 🔥 Формулы энергии

**Возобновляемая энергия:**
```
Устойчивость = Возобновляемая / Общая
Su = Renewable / Total
```

**Фотосинтетическая эффективность:**
```
Эффективность ≈ 1-2% (природа)
растения конвертируют солнечный свет
```

**Трофические уровни:**
```
Энергия_уровень_n ≈ 0.1 × Энергия_уровень_(n-1)
правило 10%
```

**Энергетический баланс:**
```
Вход = Выход + Накопление
In = Out + Storage
```

## 🦠 Формулы биоразнообразия

**Индекс Шеннона:**
```
H = -∑(pi × ln(pi))
мера разнообразия
```

**Вымирание:**
```
Скорость_вымирания ∝ 1/Площадь_среды
Ex_rate ∝ 1/Habitat_area
```

**Островная биогеография:**
```
Виды = f(Площадь, Изоляция)
Sp = f(Area, Isolation)
```

**Ключевые виды:**
```
Влияние_вида >> Биомасса_вида
Impact >> Biomass
непропорциональное значение
```

```
долговечность важна
```

```
lim(Отходы → 0)
стремление к нулю
```

## 🌍 Формулы планетарных границ

**Планетарные границы:**
```
Безопасность = Воздействие < Граница
Sa = Impact < Boundary
9 границ Земли
```

**Переломные точки:**
```
Система: Стабильная → Критическая → Коллапс
Sy: Stable → Critical → Collapse
```

**Овершут:**
```
Овершут = Потребление > 1.7 × Биоёмкость_Земли
Overshoot = Consumption > 1.7 × Earth_biocapacity
```

**День экологического долга:**
```
День = (Биоёмкость / Потребление) × 365
Ea_overshoot_day = (Bi / Co) × 365
```

## 🌿 Формулы восстановления

**Восстановление экосистемы:**
```
Восстановление = Время × Усилия × Условия
Re = Time × Effort × Conditions
```

**Ревайлдинг:**
```
Дикость = Удаление_человека + Возвращение_видов + Время
Wi = Human_removal + Species_return + Time
```

**Регенерация:**
```
Регенерация > Деградация
Regeneration > Degradation
```

**Resilience:**
```
Устойчивость = Разнообразие × Связанность / Стресс
Re = Diversity × Connectivity / Stress
```

## 🎯 Формулы действий

**Углеродная нейтральность:**
```
Выбросы = Поглощение
Emissions = Absorption
```

**Личный вклад:**
```
Воздействие = ∑(Выбор_i × Частота_i)
Impact = ∑(Choice_i × Frequency_i)
```

**Коллективное действие:**
```
Изменение = ∑(Индивидуальные_действия) × Масштаб
Ch = ∑(Individual_actions) × Scale
```

**Будущие поколения:**
```
Ответственность = Текущие_действия × Последствия_будущие
Re = Current_actions × Future_consequences
```
