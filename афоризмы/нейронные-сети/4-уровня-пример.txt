┌────────────────────────────────────────────────────────────────────────────┐
│ [1] ФОРМУЛА — Математическая абстракция                                    │
└────────────────────────────────────────────────────────────────────────────┘

y = f(Σ(wᵢ × xᵢ) + b)

где:
y — выход нейрона
xᵢ — входы (features)
wᵢ — веса (weights)
b — смещение (bias)
f — функция активации (ReLU, sigmoid, tanh)

Обучение (Backpropagation):
∂Loss/∂w = ∂Loss/∂y × ∂y/∂w

→ Градиентный спуск: w_new = w_old - η × ∂Loss/∂w
   где η — learning rate

Universal Approximation Theorem:
Нейронная сеть с одним скрытым слоем может аппроксимировать 
ЛЮБУЮ непрерывную функцию (при достаточном количестве нейронов)

Deep Learning Масштаб:
Performance ∝ Data^α × Compute^β × Architecture

→ Больше данных + больше вычислений = лучшая модель
   (до определённого предела)

┌────────────────────────────────────────────────────────────────────────────┐
│ [2] АРХЕТИП — Развёрнутая формула с компонентами                           │
└────────────────────────────────────────────────────────────────────────────┘

Neural Network = (Data × Architecture) × (Training × Optimization) × (Deployment)

Компоненты:

Data (Данные):
├─ Training set: 70-80% данных для обучения
├─ Validation set: 10-15% для подбора гиперпараметров
├─ Test set: 10-15% для финальной оценки
├─ Data augmentation: искусственное увеличение датасета
├─ Preprocessing: нормализация, очистка, токенизация
└─ Labeling: разметка данных (дорого и долго)

Architecture (Архитектура):
├─ Feedforward: простая сеть (MLP - Multilayer Perceptron)
├─ CNN (Convolutional Neural Networks): изображения, видео
├─ RNN/LSTM/GRU: последовательности, текст, временные ряды
├─ Transformer: NLP, современный стандарт (GPT, BERT)
├─ GAN (Generative Adversarial Networks): генерация изображений
├─ Diffusion Models: Stable Diffusion, DALL-E
└─ Hybrid: комбинация разных архитектур

Training (Обучение):
├─ Forward pass: данные проходят через сеть
├─ Loss calculation: сравнение предсказания с реальностью
├─ Backward pass: вычисление градиентов (backpropagation)
├─ Weight update: обновление весов (gradient descent)
├─ Epochs: количество проходов по всему датасету
└─ Batch size: количество примеров за один шаг

Optimization (Оптимизация):
├─ Optimizer: SGD, Adam, AdamW, RMSprop
├─ Learning rate: скорость обучения (критичный гиперпараметр)
├─ Learning rate scheduling: изменение LR в процессе
├─ Regularization: предотвращение переобучения
│  ├─ L1/L2 regularization: штраф за большие веса
│  ├─ Dropout: случайное отключение нейронов
│  └─ Early stopping: остановка при ухудшении на validation
├─ Batch normalization: нормализация внутри сети
└─ Gradient clipping: предотвращение exploding gradients

Популярные архитектуры:

1. CNN (Convolutional Neural Networks):
   ├─ AlexNet (2012): победа в ImageNet, начало deep learning бума
   ├─ ResNet (2015): skip connections, 152 слоя
   └─ Vision Transformer (2020): применение трансформеров к изображениям

2. Transformer (2017 - "Attention is All You Need"):
   ├─ BERT (2018): bidirectional, понимание контекста
   ├─ GPT (2018-2024): autoregressive, генерация текста
   └─ Применение: NLP, code generation, multimodal

3. Generative Models:
   ├─ GAN (2014): Generator vs Discriminator
   ├─ Diffusion Models (2020): DALL-E 2, Stable Diffusion
   └─ Применение: генерация изображений, видео, музыки

ОБЪЯСНЕНИЕ:

Нейронные сети — мощные функции аппроксимации с огромным потенциалом,
но требующие правильного подхода для успешного применения.

ИЕРАРХИЯ ВАЖНОСТИ:

1. ДАННЫЕ (70% успеха):
   • Качество > количество
   • Репрезентативность критична
   • Garbage in, garbage out

2. АРХИТЕКТУРА (20% успеха):
   • CNN для изображений
   • Transformer для текста
   • Transfer learning экономит время

3. ГИПЕРПАРАМЕТРЫ (10% успеха):
   • Fine-tuning даёт небольшое улучшение
   • Базовая модель должна работать сначала

Современные нейронные сети демонстрируют впечатляющие результаты в компьютерном
зрении, обработке естественного языка, генерации контента и многих других областях.
