# Info3 — система знаний

Репозиторий объединяет материалы о гуманитарных формулах, архетипах, алгоритмах и теоремах в рамках четырёхчастной системы представления знаний. Тематические каталоги содержат пары понятий, а `machine-readable/` — машиночитаемые форматы и примеры для AI/RAG-экспериментов.

Описание форматов и структуры см. в `machine-readable/README.md`.
