Уровни автономности (SAE J3016):
Level_0: No automation (человек делает всё)
Level_1: Driver assistance (одна функция автоматизирована)
Level_2: Partial automation (рулевое + ускорение/торможение)
Level_3: Conditional automation (система водит, но человек наготове)
Level_4: High automation (система водит в определённых условиях)
Level_5: Full automation (система водит везде, всегда)

Sense-Plan-Act Loop:
Autonomy = f(Sensing × Planning × Acting × Learning)

Reliability (надёжность):
MTBF = Total_Operating_Time / Number_of_Failures

где MTBF — Mean Time Between Failures

Для автономных систем:
• Level 4: MTBF > 1,000,000 часов
• Человек: ~100,000 миль между авариями
• Waymo: >1,000,000 миль между disengagements (2023)

Safety критерий:
P(failure) < 10^-9 per hour для critical systems

Autonomous System = (Perception × Localization) × (Planning × Control) × (Safety)

Компоненты:

Perception (Восприятие):
├─ Sensors:
│  ├─ Cameras: 8-12 камер вокруг (Tesla, Waymo)
│  │  └─ Resolution: 1-8 MP, 30-60 FPS
│  ├─ LiDAR: лазерное сканирование
│  │  ├─ 360° обзор, до 200m дальность
│  │  ├─ Point clouds: миллионы точек/сек
│  │  └─ Стоимость: $1K-$100K (Waymo использует)
│  ├─ Radar: радарное обнаружение
│  │  ├─ All-weather: работает в дождь, туман
│  │  ├─ Velocity measurement: Doppler effect
│  │  └─ Long range: до 300m
│  ├─ Ultrasonic: парковка, близкие объекты (<5m)
│  └─ IMU: инерциальные измерения (acceleration, rotation)
├─ Sensor Fusion:
│  ├─ Kalman Filter: объединение данных с разных сенсоров
│  ├─ Redundancy: если один сенсор fails, другие компенсируют
│  └─ Confidence scores: насколько уверены в детекции
├─ Object Detection:
│  ├─ Cars, pedestrians, cyclists, animals
│  ├─ Traffic signs, traffic lights
│  ├─ Road markings: lanes, crosswalks
│  └─ Obstacles: construction, debris
└─ Semantic Segmentation:
   ├─ Pixel-wise classification: road, sidewalk, building
   └─ Drivable area: где можно ехать

Localization (Локализация):
├─ GPS: 1-5m accuracy (недостаточно!)
├─ HD Maps: сантиметровая точность карт
│  ├─ Pre-mapped routes: Waymo подход
│  ├─ Lane-level detail: разметка, знаки
│  └─ Update frequency: изменения дорог
├─ Visual Odometry: отслеживание движения по камерам
├─ SLAM: Simultaneous Localization and Mapping
│  └─ Строит карту и определяет позицию одновременно
└─ Sensor matching: сравнение real-time data с HD maps

Planning (Планирование):

Mission Planning (высокий уровень):
├─ Route planning: A* pathfinding
├─ Traffic consideration: пробки, аварии
└─ Destination: куда ехать

Behavioral Planning (средний уровень):
├─ Lane keeping: удержание полосы
├─ Lane change: когда и как перестроиться
├─ Intersection handling: проезд перекрёстков
├─ Yielding: уступить дорогу
└─ Traffic light/sign obedience

Motion Planning (низкий уровень):
├─ Trajectory generation: smooth path
├─ Obstacle avoidance: объезд препятствий
├─ Comfort: минимизация jerk (рывков)
├─ Prediction: что сделают другие участники?
└─ Emergency maneuvers: экстренное торможение/уклонение

Control (Управление):
├─ Steering: поворот руля
├─ Acceleration: газ
├─ Braking: тормоза
├─ PID controllers: feedback control
└─ MPC (Model Predictive Control): оптимизация траектории

Safety Systems:

Redundancy:
├─ Dual/triple redundant sensors
├─ Backup compute: если main fails
├─ Fail-safe modes: безопасная остановка
└─ Watchdog timers: detect frozen systems

V&V (Verification & Validation):
├─ Simulation: миллионы виртуальных миль
│  ├─ CARLA, LGSVL: open-source simulators
│  ├─ Edge case testing: редкие ситуации
│  └─ Adversarial scenarios
├─ Closed-course testing: контролируемые треки
├─ Public road testing: реальные условия
│  ├─ Safety driver: готов взять управление
│  └─ Disengagement reporting: когда система fails
└─ Regulatory approval: DMV, NHTSA

Типы автономных систем:

Автономные автомобили:
├─ Waymo (Google): L4, robotaxis (SF, Phoenix)
├─ Cruise (GM): L4, robotaxis (SF)
├─ Tesla Autopilot/FSD: L2, consumer cars
├─ Zoox (Amazon): L4, custom vehicles
└─ Mobileye: L2-L4, различные производители

Дроны:
├─ DJI: consumer drones, obstacle avoidance
├─ Military: reconnaissance, targeted strikes
├─ Delivery: Amazon Prime Air, Zipline (медицина)
└─ Inspection: инфраструктура, сельское хозяйство

Роботы:
├─ Warehouse: Kiva (Amazon), autonomo us picking
├─ Delivery: Starship, Nuro
├─ Agriculture: autonomous tractors, harvesters
└─ Underwater: AUVs для исследования океана

Проблемы и вызовы:

Технические:
├─ Long tail problem: редкие edge cases
├─ Sensor limitations: плохая погода, ночь
├─ Prediction uncertainty: поведение людей непредсказуемо
├─ Computational cost: real-time processing
└─ Mapping: поддержка актуальности HD maps

Регуляторные:
├─ Liability: кто виноват при аварии?
├─ Insurance: как страховать autonomy?
├─ Testing standards: требования безопасности
└─ Data privacy: cameras собирают много данных

Этические:
├─ Trolley problem: кого спасать при неизбежной аварии?
├─ Job displacement: водители такси, грузовиков
├─ Access: доступность для всех или только богатых?
└─ Surveillance: tracking движения людей

ТЕОРЕМА:

"Автономность — это не бинарность (есть/нет), а спектр. 
И последние 10% сложнее первых 90%"

ОБЪЯСНЕНИЕ:

90/90 RULE в автономных системах:
"Первые 90% задачи занимают 90% времени. 
Оставшиеся 10% занимают другие 90% времени."

ПОЧЕМУ ТАК?

1. LONG TAIL PROBLEM:
   • 90% driving scenarios: прямая дорога, хорошая погода
   • 10% edge cases: construction, emergency vehicles, странное поведение людей
   • НО эти 10% критичны для безопасности

2. РАЗНИЦА МЕЖДУ УРОВНЯМИ:
   • Level 2 → 3: огромный скачок ответственности
   • Level 2: человек ответственен всегда
   • Level 3: система ответственна, но может передать управление
   • Level 4: система полностью ответственна (в определённых условиях)

3. ПРИМЕРЫ EDGE CASES:
   • Полицейский жестами направляет трафик
   • Дети выбегают за мячом
   • Перевёрнутый грузовик на дороге
   • Снег закрыл разметку и знаки
   • Строительство изменило дорогу (HD map устарела)

ТЕКУЩЕЕ СОСТОЯНИЕ (2024):

WAYMO (Alphabet):
• Level 4: robotaxis без водителя
• Геозона: San Francisco, Phoenix, Los Angeles
• Ограничения: только определённые районы, хорошая погода
• Успех: 1M+ поездок/месяц
• НО: стоимость астрономическая, масштабирование сложно

CRUISE (GM):
• Level 4: robotaxis
• Проблемы:
  - 2023: приостановка после инцидентов
  - Блокирование движения, аварии
  - Regulatory pushback
• Демонстрирует сложность deployment

TESLA FSD (Full Self-Driving):
• Level 2: человек всегда ответственен
• Камеры only (no LiDAR)
• Millions of cars, enormous data
• Beta testing на публике (спорно!)
• Впечатляющий прогресс, но всё ещё L2

БАЛАНС ПОДХОДОВ:

Waymo: "Perfect before scale"
• Ждут пока система очень надёжна
• Тогда масштабируют
• Медленно, дорого, но безопаснее

Tesla: "Scale to perfect"
• Миллионы машин собирают данные
• Rapid iteration, fleet learning
• Быстрее, дешевле, но рискованнее

REALITY CHECK:

Обещания не сбылись:
• 2014 Elon Musk: "Full autonomy in 2-3 years"
• 2015 Google: "Robotaxis к 2020"
• 2016 Ford: "L4 к 2021"

Сейчас (2024):
• L4 существует, но ограничен географически
• L5 (anywhere, anytime) — ещё десятилетия?
• Complexity недооценили

УРОК:
99% reliability недостаточно. Нужно 99.9999%+

• Autonomous systems не могут ошибаться
• Edge cases убивают
• Последний 1% требует экспоненциально больше работы

ПРИМЕРЫ УСПЕХОВ И ПРОВАЛОВ:

УСПЕХ: Waymo Robotaxis (SF, Phoenix)
• >20 million autonomous miles
• Безопаснее человека (по их данным)
• Коммерческий сервис, платящие клиенты
• НО: ограниченная зона, дорого

ПРОВАЛ: Uber Self-Driving Car Fatal Crash (2018)
• Pedestrian killed в Tempe, Arizona
• Система видела человека, но классифицировала неправильно
• Safety driver отвлеклась (смотрела видео)
• Результат: Uber продал autonomy division

ПРОВАЛ: Tesla Autopilot Crashes
• Multiple fatalities связаны с Autopilot
• Drivers over-relying на L2 system
• Marketing: "Full Self-Driving" вводит в заблуждение
• NHTSA investigations

УСПЕХ: Waymo Safety Record
• 0 fatalities за 20+ million miles
• Значительно меньше incidents чем Cruise
• Демонстрирует: возможно, но требует осторожности

ЗАКЛЮЧЕНИЕ:

Автономные системы прошли от sci-fi к реальности, но не так быстро, как обещали.

Прогресс реален:
• L4 robotaxis существуют
• Миллионы миль autonomously
• Safety улучшается

НО challenges остаются:
• Edge cases
• Regulatory uncertainty
• Public trust
• Economics (очень дорого)

Будущее: постепенное расширение operational design domains,
не "full autonomy everywhere" за раз.

"Easy things are hard, and hard things are exponentially harder"
