│ [1] ФОРМУЛА — Математическая абстракция                                    │

Диагностическая точность:
Sensitivity (Чувствительность) = TP / (TP + FN)
Specificity (Специфичность) = TN / (TN + FP)

где:
TP (True Positive) — правильно выявленные больные
TN (True Negative) — правильно определённые здоровые
FP (False Positive) — ложная тревога (здоровый определён как больной)
FN (False Negative) — пропуск болезни (больной определён как здоровый)

Trade-off:
• Высокая Sensitivity → больше FP (скрининг: лучше перестраховаться)
• Высокая Specificity → больше FN (подтверждающий тест: избежать ложных диагнозов)

Positive Predictive Value:
PPV = TP / (TP + FP)

→ Вероятность болезни при положительном тесте
→ Зависит от распространённости болезни (prevalence)!

Терапевтическое окно (Therapeutic Window):
TW = Toxic_Dose / Effective_Dose

→ Чем больше, тем безопаснее препарат
→ Узкое окно (например, варфарин) требует точного дозирования

Доза облучения (Imaging):
Эффективная доза (мЗв):
• Рентген грудной клетки: 0.02 мЗв
• Маммография: 0.4 мЗв
• КТ грудной клетки: 7 мЗв
• КТ всего тела: 10-20 мЗв
• ПЭТ-КТ: 14-25 мЗв

Сравнение: Фоновое излучение ~3 мЗв/год

Принцип ALARA: As Low As Reasonably Achievable
→ Минимизировать облучение при сохранении диагностической ценности

Medical Device = (Diagnostic × Therapeutic) × (Monitoring × Imaging) × (AI)

Компоненты:

Diagnostic (Диагностика):
├─ In vitro (Вне тела):
│  ├─ Анализы крови: биохимия, гормоны, маркеры
│  ├─ Генетические тесты: ДНК секвенирование, PCR
│  ├─ Микробиология: культуры, антибиотикограммы
│  └─ Rapid tests: COVID-19, pregnancy, glucose
├─ In vivo (В теле):
│  ├─ Эндоскопия: камера внутрь (ЖКТ, легкие, мочевой пузырь)
│  ├─ Биопсия: взятие ткани для анализа
│  └─ Functional tests: ЭКГ, спирометрия, стресс-тесты
└─ Point-of-Care:
   ├─ Glucose meters: для диабетиков
   ├─ Pulse oximeters: сатурация кислорода
   └─ Portable ultrasound: Butterfly IQ

Therapeutic (Лечение):
├─ Surgical (Хирургия):
│  ├─ Robotic surgery: da Vinci (4 руки, 10x увеличение, тремор-фильтр)
│  ├─ Minimally invasive: лапароскопия, эндоваскулярные
│  ├─ Laser surgery: LASIK (глаза), опухоли
│  └─ Cryotherapy: замораживание (бородавки, опухоли)
├─ Radiation:
│  ├─ Radiotherapy: внешнее облучение опухолей
│  ├─ Brachytherapy: радиоактивные источники внутрь
│  ├─ Proton therapy: точное облучение (дорого)
│  └─ Gamma Knife: радиохирургия мозга
├─ Electrical:
│  ├─ Pacemaker: стимуляция сердца
│  ├─ Defibrillator: ICD (implantable cardioverter-defibrillator)
│  ├─ Deep brain stimulation: Parkinson's, depression
│  └─ TMS (Transcranial Magnetic Stimulation): неинвазивная стимуляция
├─ Drug delivery:
│  ├─ Insulin pumps: автоматическая доставка для диабетиков
│  ├─ Infusion pumps: контролируемое введение лекарств
│  ├─ Inhalers: астма, COPD
│  └─ Transdermal patches: никотин, контрацептивы, обезболивающие
└─ Implants:
   ├─ Artificial joints: hip, knee replacement
   ├─ Cochlear implants: восстановление слуха
   ├─ Stents: поддержка сосудов
   └─ Prosthetics: бионические конечности

Monitoring (Мониторинг):
├─ Vital signs:
│  ├─ ECG: электрокардиограмма (сердечный ритм)
│  ├─ Blood pressure: автоматические тонометры
│  ├─ Temperature: инфракрасные, контактные
│  └─ Respiratory rate: капнография
├─ Wearables:
│  ├─ Smartwatches: Apple Watch (ЭКГ, AFib detection), Fitbit
│  ├─ CGM (Continuous Glucose Monitoring): Dexcom, Libre
│  ├─ ECG patches: Zio Patch (2 недели непрерывной записи)
│  └─ Sleep trackers: apnea detection
├─ Remote monitoring:
│  ├─ Telehealth: видеоконсультации
│  ├─ RPM (Remote Patient Monitoring): передача данных врачу
│  └─ AI alerts: предупреждение о ухудшении
└─ ICU monitoring:
   ├─ Invasive BP: артериальная линия
   ├─ Central venous pressure
   ├─ Intracranial pressure: после травм мозга
   └─ Multi-parameter monitors: всё на одном экране

Imaging (Визуализация):
├─ X-Ray (Рентген):
│  ├─ Digital radiography: быстрее, меньше доза
│  ├─ Fluoroscopy: real-time рентген (catheter guidance)
│  └─ Mammography: скрининг рака груди
├─ CT (Computed Tomography):
│  ├─ Spiral CT: быстрое 3D сканирование
│  ├─ Dual-energy CT: разделение тканей
│  ├─ CT angiography: визуализация сосудов
│  └─ Применение: травмы, опухоли, сосуды
├─ MRI (Magnetic Resonance Imaging):
│  ├─ Structural MRI: анатомия (мозг, суставы)
│  ├─ Functional MRI: активность мозга
│  ├─ MR angiography: сосуды без контраста
│  ├─ Преимущества: нет радиации, отличные мягкие ткани
│  └─ Недостатки: дорого, долго, шумно, нельзя с металлом
├─ Ultrasound (УЗИ):
│  ├─ 2D: стандартная визуализация
│  ├─ 3D/4D: объёмная визуализация (плод)
│  ├─ Doppler: кровоток
│  ├─ POCUS (Point-of-Care): портативные устройства
│  └─ Преимущества: дешёво, безопасно, real-time
├─ Nuclear Medicine:
│  ├─ PET (Positron Emission Tomography): метаболизм (онкология)
│  ├─ SPECT: функциональная визуализация
│  └─ Bone scans: метастазы, инфекции
└─ Optical:
   ├─ Endoscopy: внутренние органы
   ├─ OCT (Optical Coherence Tomography): сетчатка глаза
   └─ Fluorescence imaging: хирургия под контролем

AI in Medicine:
├─ Image analysis:
│  ├─ Радиология: детекция опухолей, переломов
│  ├─ Патология: анализ биопсий
│  ├─ Дерматология: классификация кожных заболеваний
│  └─ Офтальмология: диабетическая ретинопатия
├─ Diagnostics:
│  ├─ IBM Watson: онкология (частично провалился)
│  ├─ Symptom checkers: Buoy Health, Ada
│  └─ Genomics: интерпретация генетических вариантов
├─ Drug discovery:
│  ├─ AlphaFold: предсказание структуры белков
│  ├─ Molecule design: AI генерирует кандидаты
│  └─ Clinical trial optimization
├─ Predictive analytics:
│  ├─ Sepsis prediction: early warning scores
│  ├─ Readmission risk: кто вернётся в больницу
│  └─ Disease progression: как быстро ухудшится
└─ Personalized medicine:
   ├─ Treatment recommendations: на основе генетики
   ├─ Drug dosing: индивидуальный подбор дозы
   └─ Risk stratification: кому нужен скрининг

Regulatory (Регулирование):
├─ FDA (США):
│  ├─ Class I: низкий риск (bandages)
│  ├─ Class II: умеренный риск (большинство устройств)
│  ├─ Class III: высокий риск (pacemakers, implants) — нужны клинические испытания
│  └─ 510(k): доказательство эквивалентности существующему устройству
├─ CE Mark (Европа):
│  ├─ MDR (Medical Device Regulation): новые строгие правила (2021)
│  └─ Notified bodies: сертификация
├─ Clinical trials:
│  ├─ Phase I: безопасность (20-80 человек)
│  ├─ Phase II: эффективность (100-300)
│  ├─ Phase III: large-scale (1,000-3,000)
│  └─ Phase IV: post-market surveillance
└─ Ethics:
   ├─ Informed consent: пациент понимает риски
   ├─ Privacy: HIPAA (США), GDPR (Европа)
   └─ Equity: доступ для всех, не только богатых

ТЕОРЕМА:

"Медицинские технологии могут диагностировать и лечить, 
но не могут заменить врача. AI — это инструмент, не замена эмпатии и суждения"

ОБЪЯСНЕНИЕ:

РЕВОЛЮЦИЯ МЕДТЕХНОЛОГИЙ:

XIX век: Рентген (1895) — первая внутренняя визуализация без разрезов
XX век: Антибиотики, КТ, МРТ, УЗИ, кардиостимуляторы, трансплантация
XXI век: Геномика, роботическая хирургия, AI, телемедицина, носимые устройства

СЕГОДНЯШНИЕ ВОЗМОЖНОСТИ:

1. Диагностика на уровне экспертов (иногда лучше):
   • AI для чтения маммограмм: сравним с радиологами
   • Диабетическая ретинопатия: FDA-одобренный AI (IDx-DR)
   • Кожные заболевания: AI классифицирует с точностью дерматологов

2. Минимально инвазивные процедуры:
   • Роботическая хирургия: меньше травма, быстрее восстановление
   • Эндоваскулярные: доступ через сосуды вместо открытой операции
   • Радиохирургия: без разрезов вообще

3. Персонализированная медицина:
   • Генетическое тестирование: риски заболеваний
   • Pharmacogenomics: какие лекарства подойдут
   • Таргетная терапия: лечение основано на генетике опухоли

НО: ОГРАНИЧЕНИЯ

1. AI не понимает контекст:
   • Может найти паттерн, но не знает "почему"
   • Не учитывает уникальную историю пациента
   • Black box: непонятно, как принято решение

2. Технологии дороги:
   • da Vinci robot: $2 млн за систему
   • MRI: $1-3 млн за машину
   • Неравный доступ: богатые vs бедные страны

3. Человеческий фактор критичен:
   • Эмпатия: понимание страхов и переживаний пациента
   • Этика: сложные решения конца жизни
   • Holistic view: учёт психологических и социальных факторов

БАЛАНС:
Технологии + Врач > Технологии или Врач по отдельности

AI как ассистент:
• Предлагает дифференциальный диагноз
• Предупреждает о пропущенных находках
• Освобождает время врача для пациента

Врач принимает финальное решение:
• Учитывает контекст
• Общается с пациентом
• Несёт ответственность

ЗАКЛЮЧЕНИЕ:

Медицинские технологии трансформируют здравоохранение, делая диагностику 
точнее, лечение эффективнее, и открывая новые возможности.

НО: Медицина — это искусство И наука. 
Технологии усиливают врача, но не заменяют человечность в медицине.

"Cure sometimes, treat often, comfort always" — остаётся истиной в эру AI.
