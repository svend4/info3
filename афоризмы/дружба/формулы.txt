# Дружба — Формулы дружеских отношений

## 🤝 Базовые формулы дружбы

**Дружба:**
```
Дружба = Доверие² + Время + Общие_интересы
Fr = Tr² + T + Sh_interests
```

**Настоящая дружба:**
```
Настоящая = (Взаимность × Искренность × Поддержка) / Корысть
Re_friendship = (Re × Si × Su) / Se
```

**Крепость дружбы:**
```
Крепость = (Время_вместе × Общий_опыт × Доверие)^(1/3)
St = (T_together × Sh_experience × Tr)^(1/3)
```

**Близкий друг:**
```
Близкий = Доверие + Понимание + История + Принятие
Cl = Tr + Un + Hi + Ac
```

## ⏰ Формулы времени в дружбе

**Время и дружба:**
```
Дружба ∝ Время × Качество_общения
Fr ∝ T × Q_communication
```

**Поддержание дружбы:**
```
Поддержание = Контакт × Усилия / Расстояние
Ma = Co × Ef / Di
```

**Проверка временем:**
```
Прочность = ∫(Моменты × Поддержка) dt
St = ∫(Mo × Su) dt
```

**Дружба на расстоянии:**
```
Связь = Общение / (Расстояние × Время_разлуки)
Bo = Co / (Di × T_apart)
```

## 💎 Формулы ценности дружбы

**Ценность друга:**
```
Ценность = Поддержка + Честность + Веселье + Лояльность
Va = Su + Ho + Fu + Lo
```

**Качество vs Количество:**
```
5 настоящих > 500 знакомых
5 real > 500 acquaintances
```

**Номер Данбара:**
```
Близких_друзей ≤ 5
Друзей ≤ 15
Знакомых ≤ 150
когнитивные ограничения
```

**Инвестиция в дружбу:**
```
Отдача = Вложенное_время × Внимание × Забота
Re = Invested_time × At × Ca
```

## 🔍 Формулы проверки дружбы

**Настоящий друг:**
```
Друг_настоящий = Поддержка_в_трудностях / Поддержка_в_радости ≈ 1
Re_friend = Su_hard_times / Su_good_times ≈ 1
```

**Проверка:**
```
Проверка = Кризис × Время × Выбор
Te = Cr × T × Ch
```

**Токсичная дружба:**
```
Токсичность = Брать / Давать > 2
To = Take / Give > 2
односторонность
```

**Лояльность:**
```
Лояльность = Верность × Защита × Секреты
Lo = Fa + Pr + Se
```

## 🌱 Формулы развития дружбы

**Стадии дружбы:**
```
Знакомство → Приятельство → Дружба → Близкая_дружба
Ac → Bu → Fr → Cl_friendship
```

**Формирование:**
```
Новая_дружба = Симпатия + Близость + Время + Общее
Ne_friendship = Li + Pr + T + Sh
```

**Углубление:**
```
Глубина = Самораскрытие × Взаимность × Уязвимость
De = SD × Re × Vu
```

**Превращение в близких:**
```
Близкие = Время > 200 часов + Глубокие_разговоры
Cl = Time > 200h + Deep_talks
```

## 💬 Формулы общения

**Качество общения:**
```
Качество = Честность + Юмор + Глубина + Понимание
Q = Ho + Hu + De + Un
```

**Темы разговоров:**
```
Связь = Поверхностные < Средние < Глубокие
Bo = Shallow < Medium < Deep
глубокие темы создают связь
```

**Слушание:**
```
Дружба = Говорить × Слушать
Fr = Speak × Listen
баланс важен
```

**Конфликты:**
```
Разрешение = Честность + Прощение + Понимание
Re = Ho + Fo + Un
```

## 🎭 Формулы типов дружбы

**Детская дружба:**
```
Детская = Близость + Игра
Ch_friendship = Pr + Play
```

**Взрослая дружба:**
```
Взрослая = Общие_ценности + Взаимная_поддержка + История
Ad_friendship = Sh_values + Mu_support + Hi
```

**Рабочая дружба:**
```
Рабочая = Профессионализм + Личное / Иерархия
Wo_friendship = Pr + Pe / Hi
```

**Онлайн-дружба:**
```
Онлайн = Общение_виртуальное × Схожесть / Физическая_дистанция
On_friendship = Vi_communication × Si / Ph_distance
```

## 🔄 Формулы взаимности

**Взаимность:**
```
Взаимность = Отдача_A ≈ Отдача_B
Re = Give_A ≈ Give_B
```

**Баланс:**
```
Баланс = |Вклад_A - Вклад_B| → 0
Ba = |Co_A - Co_B| → 0
минимальная разница
```

**Односторонность:**
```
Односторонность = |Вклад_A - Вклад_B| > Порог
One_sided = |Co_A - Co_B| > Th
несбалансированность
```

**Эксплуатация:**
```
Эксплуатация = Брать >> Давать
Ex = Take >> Give
```

## 💔 Формулы потери дружбы

**Разрыв:**
```
P(разрыв) = (Конфликты + Расстояние + Изменения) / (История + Усилия)
P(break) = (Cf + Di + Ch) / (Hi + Ef)
```

**Причины:**
```
Потеря = Предательство | Расстояние | Изменение | Отсутствие_усилий
Lo = Be | Di | Ch | La_effort
```

**Восстановление:**
```
Восстановление = Прощение + Время + Желание_обоих
Re = Fo + T + Wi_both
```

**Дрейф:**
```
Дрейф = Время × (1 - Усилия)
Dr = T × (1 - Ef)
естественное отдаление
```

## 🌟 Формулы идеальной дружбы

**Идеальный друг:**
```
Идеал = Верность + Честность + Поддержка + Юмор + Принятие
Id = Lo + Ho + Su + Hu + Ac
```

**Золотое правило:**
```
Относись_к_другу = Как_хочешь_чтобы_относились_к_тебе
Treat_friend = As_want_treated
```

**Безусловное принятие:**
```
Принятие ≠ f(Условия)
Ac ≠ f(Conditions)
```

**Аристотелевы типы:**
```
Дружба = Полезность | Удовольствие | Добродетель
Fr = Utility | Pleasure | Virtue
высшая — добродетели
```

## 🎯 Формулы поддержки

**Поддержка:**
```
Поддержка = Эмоциональная + Практическая + Информационная + Компания
Su = Em + Pr + In + Co
```

**В трудные времена:**
```
Ценность = Поддержка_в_кризис / Поддержка_обычно > 1
Va = Su_crisis / Su_normal > 1
```

**Присутствие:**
```
Присутствие > Советы
Pr > Ad
иногда нужно просто быть рядом
```

**Эмпатия:**
```
Эмпатия = Понимание × Сочувствие
Em = Un × Sy
```

## 🎉 Формулы радости дружбы

**Радость:**
```
Радость_общая = Радость_индивидуальная × Разделение
Jo_shared = Jo_individual × Sharing
разделённая радость удваивается
```

**Веселье:**
```
Веселье = Юмор + Игра + Безопасность
Fu = Hu + Play + Sa
```

**Воспоминания:**
```
Связь = ∑(Воспоминания_общие × Эмоция)
Bo = ∑(Me_shared × Em)
```

**Приключения:**
```
Приключения_вместе = Новизна + Вызов + Компания
Ad_together = No + Ch + Co
```

## 🧩 Формулы совместимости

**Совместимость:**
```
Совместимость = (Сходства + Комплементарность) / Противоречия
Co = (Si + Comp) / Cont
```

**Общие интересы:**
```
Связь ∝ ∑(Интересы_общие)
Bo ∝ ∑(In_shared)
```

**Ценности:**
```
Крепость ∝ Совпадение_ценностей
St ∝ Values_alignment
```

**Темп жизни:**
```
Комфорт = |Темп_A - Темп_B| → 0
Co = |Pa_A - Pa_B| → 0
```

## 🌐 Формулы дружеских кругов

**Круги общения:**
```
Круги = Близкие < Друзья < Знакомые < Контакты
Ci = Close < Friends < Acquaintances < Contacts
```

**Социальный капитал:**
```
Капитал = ∑(Друзья × Качество_связи × Взаимность)
Ca = ∑(Fr × Q_bond × Re)
```

**Сетевой эффект:**
```
Ценность_сети ∝ n (линейно для дружбы)
не квадратично, как в технологиях
```

**Группа друзей:**
```
Динамика_группы = ∑Связи_попарные - Конфликты + Общие_цели
Gr_dynamics = ∑Pa_bonds - Cf + Sh_goals
```

## 💭 Формулы доверия

**Доверие:**
```
Доверие = ∫(Честность × Надёжность × Время) dt
Tr = ∫(Ho × Re × T) dt
```

**Секреты:**
```
Доверие ∝ Секреты_сохранённые
Tr ∝ Secrets_kept
```

**Уязвимость:**
```
Близость = Уязвимость × Принятие
Cl = Vu × Ac
```

**Предательство:**
```
Восстановление_доверия = Время × Раскаяние × Действия
Tr_recovery = T × Re × Ac
```

## 🔄 Формулы динамики

**Циклы дружбы:**
```
Дружба(t) = Подъёмы + Спады
Fr(t) = Ups + Downs
естественные колебания
```

**Обновление:**
```
Обновление = Новый_опыт × Откровенность
Re = New_experience × Op
```

**Рутина:**
```
Рутина может укрепить или ослабить
зависит от качества
```

**Эволюция:**
```
Дружба(t+1) = Дружба(t) + Изменения × Адаптация
Fr(t+1) = Fr(t) + Ch × Ad
```

## 🎁 Формулы щедрости

**Щедрость:**
```
Щедрость = Давать > Ожидать_взамен
Ge = Give > Expect_back
```

**Помощь:**
```
Помощь = Время + Усилия + Ресурсы
He = T + Ef + Re
```

**Жертва:**
```
Жертва_здоровая ≤ 0.3 × Себя
Sa_healthy ≤ 0.3 × Self
```

**Взаимопомощь:**
```
Взаимопомощь = Помощь_A ⇔ Помощь_B (со временем)
Mu_help = Help_A ⇔ Help_B (over time)
```
