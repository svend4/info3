# Психология и эмоции — Формулы человеческой психики

## 🧠 Базовые психологические формулы

**Поведение:**
```
Поведение = f(Личность, Среда)
B = f(P, E)
формула Левина
```

**Мотивация:**
```
Мотивация = Ожидание × Ценность
M = E × V
теория ожидаемой ценности
```

**Эмоция:**
```
Эмоция = Событие × Оценка × Физиология
E = Ev × Ap × Ph
```

## 💭 Когнитивные формулы

**Рабочая память:**
```
Ёмкость = 7 ± 2 элемента
Capacity = 7 ± 2 items
закон Миллера
```

**Внимание:**
```
Внимание = Стимул × Мотивация / Отвлечения
At = St × Mo / Di
```

**Когнитивная нагрузка:**
```
Нагрузка = Внутренняя + Внешняя + Связанная
Load = In + Ex + Ge
```

**Ментальные модели:**
```
Понимание = Модель(Реальность)
U = Model(Reality)
```

## 😊 Формулы счастья

**Субъективное благополучие:**
```
Счастье = Удовлетворённость_жизнью + Позитивный_аффект - Негативный_аффект
H = LS + PA - NA
```

**Адаптация:**
```
Счастье(t) → Базовый_уровень
Hedonic_adaptation
```

**Поток (Flow):**
```
Поток = Навыки ≈ Вызов
Flow = Skills ≈ Challenge
оптимальный опыт
```

**Благодарность:**
```
Счастье ∝ Благодарность
H ∝ Gratitude
```

## 😰 Формулы стресса и тревоги

**Стресс:**
```
Стресс = Требования / Ресурсы
S = De / Re
```

**Тревога:**
```
Тревога = Угроза × Неопределённость / Контроль
An = Th × Un / Co
```

**Выгорание:**
```
Выгорание = (Стресс × Время) / (Восстановление + Смысл)
Bu = (S × T) / (Re + Me)
```

**ПТСР:**
```
ПТСР = Травма × Уязвимость / (Поддержка + Копинг)
PTSD = Tr × Vu / (Su + Co)
```

## 💪 Формулы устойчивости

**Резилиентность:**
```
Устойчивость = Адаптивность + Поддержка + Смысл
Re = Ad + Su + Me
```

**Копинг:**
```
Копинг = Проблемно-фокусированный + Эмоционально-фокусированный
C = PF + EF
```

**Самоэффективность:**
```
Уверенность = Успехи / (Неудачи + Страх)
Co = Su / (Fa + Fe)
```

**Посттравматический рост:**
```
Рост = Травма × Осмысление × Поддержка
PTG = Tr × Me × Su
```

## 🎯 Мотивационные формулы

**Теория самоопределения:**
```
Мотивация_внутренняя = Автономия + Компетентность + Связь
In_motivation = Au + Co + Re
```

**Иерархия Маслоу:**
```
Потребности: Физиология < Безопасность < Любовь < Уважение < Самоактуализация
```

**Прокрастинация:**
```
Прокрастинация = 1 / (Ожидание × Ценность × Импульсивность × Дедлайн)
Pr = 1 / (E × V × I × D)
```

**Целеполагание:**
```
Достижение = Цель_SMART × Приверженность × Обратная_связь
Ac = Go_SMART × Co × Fe
```

## 🧘 Формулы осознанности

**Осознанность:**
```
Осознанность = Внимание_настоящему + Принятие
Mi = At_present + Ac
```

**Медитация:**
```
Эффект = Практика × Время × Регулярность
Ef = Pr × T × Re
```

**Эмоциональная регуляция:**
```
Регуляция = Осознание + Принятие + Действие
Re = Aw + Ac + Ac
```

## 👥 Социально-психологические формулы

**Атрибуция:**
```
Успех_свой = Способности + Усилия
Неудача_свой = Обстоятельства
фундаментальная ошибка атрибуции
```

**Конформизм:**
```
Конформизм = Давление_группы / (Уверенность + Независимость)
Co = Gr_pressure / (Co + In)
```

**Когнитивный диссонанс:**
```
Дискомфорт = |Убеждение₁ - Убеждение₂|
Di = |Be₁ - Be₂|
```

**Социальное сравнение:**
```
Самооценка = Я / Другие
SE = Self / Others
```

## 💔 Формулы отношений

**Привязанность:**
```
Привязанность = Безопасная | Тревожная | Избегающая
At = Secure | Anxious | Avoidant
```

**Близость:**
```
Близость = Самораскрытие × Взаимность × Время
In = SD × Re × T
```

**Эмпатия:**
```
Эмпатия = Понимание_когнитивное + Отклик_эмоциональный
Em = U_cognitive + R_emotional
```

**Любовь (треугольник Стернберга):**
```
Любовь = Близость + Страсть + Обязательство
Lo = In + Pa + Co
```

## 🧩 Формулы личности

**Большая пятёрка:**
```
Личность = Открытость + Добросовестность + Экстраверсия + Доброжелательность + Нейротизм
P = O + C + E + A + N
```

**Самооценка:**
```
Самооценка = Успехи / Притязания
SE = Su / As
формула Джеймса
```

**Идентичность:**
```
Я = ∑(Роли × Ценности × Опыт)
I = ∑(Ro × Va × Ex)
```

**Характер:**
```
Характер = Темперамент + Опыт + Воспитание
Ch = Te + Ex + Ed
```

## 🎭 Эмоциональные формулы

**Базовые эмоции:**
```
Эмоции = {Радость, Грусть, Страх, Гнев, Удивление, Отвращение}
```

**Эмоциональный интеллект:**
```
EQ = Осознание + Управление + Эмпатия + Социальные_навыки
EQ = Aw + Ma + Em + SS
```

**Регуляция эмоций:**
```
Регуляция = Переоценка + Подавление + Принятие
Re = Re + Su + Ac
```

**Аффективное прогнозирование:**
```
Ожидаемая_эмоция ≠ Реальная_эмоция
E_expected ≠ E_actual
impact bias
```

## 🔄 Формулы изменений

**Изменение поведения:**
```
Изменение = Готовность × Способность × Триггер
Ch = Re × Ab × Tr
модель Фогга
```

**Формирование привычки:**
```
Привычка = Сигнал → Действие → Награда × Повторение^Время
Ha = Cue → Ac → Re × Rep^T
```

**Стадии изменения:**
```
Предобдумывание → Обдумывание → Подготовка → Действие → Поддержание
Pr → Co → Pr → Ac → Ma
```

**Рецидив:**
```
P(рецидив) = Триггер × Тяга / (Копинг + Поддержка)
P(relapse) = Tr × Cr / (Co + Su)
```

## 🧠 Нейропсихологические формулы

**Нейропластичность:**
```
Изменение_мозга = Практика × Время × Внимание
Br_change = Pr × T × At
```

**Нейромедиаторы и настроение:**
```
Настроение = f(Серотонин, Дофамин, Норадреналин, Окситоцин)
Mo = f(Se, Do, No, Ox)
```

**Память:**
```
Долговременная_память = Кратковременная × Повторение × Значимость
LTM = STM × Re × Si
```

**Внимание:**
```
Фокус = Интерес / (Отвлечения + Усталость)
Fo = In / (Di + Fa)
```

**Кривая забывания:**
```
R(t) = e^(-t/S)
где S — сила памяти
```

**Эффект интервала:**

Запоминание ∝ 1/√(Интервалы_между_повторениями)
```

**Зона ближайшего развития:**
```
Обучение_оптимальное = Знания + (Помощь × Вызов)
Le_optimal = K + (He × Ch)
```

**Практика:**
```
Мастерство = Качество_практики × Время
Ma = Q_practice × T

## 💊 Клинические формулы

**Депрессия:**
```
Депрессия = (Стресс + Уязвимость) - (Защитные_факторы)
De = (St + Vu) - (Pr)
```

**Тревожное расстройство:**
```
Тревога_патологическая = Тревога > Порог × Длительность
An_pathological = An > Th × Du
```

**Выздоровление:**
```
Выздоровление = Терапия + Лекарства + Поддержка + Время
Re = Th + Me + Su + T
```

**Инсайт:**
```
Инсайт = Осознание_проблемы + Понимание_причин + Мотивация_изменений
In = Aw_problem + U_causes + Mo_change
```

## 🌈 Позитивная психология

**Благополучие (PERMA):**
```
Благополучие = Позитивные_эмоции + Вовлечённость + Отношения + Смысл + Достижения
We = PE + En + Re + Me + Ac
```

**Оптимизм:**
```
Оптимизм = Позитивные_ожидания / Негативные_ожидания
Op = PE / NE
```

**Смысл жизни:**
```
Смысл = Цель + Значимость + Когерентность
Me = Pu + Si + Co
```

**Сильные стороны:**
```
Процветание = Использование_сильных_сторон × Частота
Fl = Use_strengths × Fr
```

## 🔮 Формулы восприятия

**Восприятие реальности:**
```
Восприятие = Стимул × Ожидания × Контекст
Pe = St × Ex × Co
```

**Внимательная слепота:**
```
Замечено = Внимание × Ожидание
No = At × Ex
незамеченное ∉ Внимание
```

**Когнитивные искажения:**
```
Реальность_воспринятая ≠ Реальность_объективная
Re_perceived ≠ Re_objective
```

**Прайминг:**
```
Реакция(стимул) = Реакция_базовая + Прайминг_эффект
Re(stimulus) = Re_base + Pr_effect
```
