┌────────────────────────────────────────────────────────────────────────────┐
│  [1] ФОРМУЛА — самое общее, абстрактное, техническое                      │
└────────────────────────────────────────────────────────────────────────────┘

L = T × Q

где:
L (Life value) — ценность жизни
T (Time) — время, которое есть
Q (Quality) — качество использования времени

Альтернативная формула восприятия времени:

P = E / (A + R)

где:
P (Perceived time) — воспринимаемое время
E (Experience novelty) — новизна опыта
A (Age) — возраст
R (Routine) — рутинность жизни

Чем старше и рутиннее, тем быстрее течёт время.

┌────────────────────────────────────────────────────────────────────────────┐
│  [2] АРХЕТИП — расширенная формула, безличная, детальная                  │
└────────────────────────────────────────────────────────────────────────────┘

АРХЕТИП МУДРОГО ОТНОШЕНИЯ КО ВРЕМЕНИ

Осмысленная жизнь = (Осознание конечности × Присутствие в моменте) ×
                    (Приоритеты + Действия согласно ценностям) ÷
                    (Прокрастинация + Отвлечения + Сожаления) +
                    Принятие старения

где компоненты детализированы:

• Осознание конечности (Awareness of Mortality):
  - Жизнь ограничена (примерно 80 лет = 29,200 дней)
  - Время = невосполнимый ресурс
  - Каждая минута, потраченная на X, не может быть потрачена на Y
  - Memento mori: помни о смерти (не для страха, а для осознанности)
  - Парадокс: осознание смерти делает жизнь ценнее

• Присутствие в моменте (Being Present):
  - НЕ жить прошлым (сожаления, ностальгия)
  - НЕ жить будущим (тревога, откладывание жизни)
  - Жить СЕЙЧАС (единственный момент, который реально существует)
  - Mindfulness: осознанное присутствие
  - "Вчера — история, завтра — тайна, сегодня — подарок (present)"

• Приоритеты (Priorities):
  - Определить, что действительно важно (не срочно, а важно)
  - Матрица Эйзенхауэра: важное/срочное vs неважное/несрочное
  - Фокус на важном (отношения, здоровье, рост)
  - Отказ от неважного (даже если кажется срочным)

• Действия согласно ценностям (Value-Aligned Actions):
  - Не просто знать ценности, а ЖИТЬ согласно им
  - Время = валюта жизни, на что её тратишь?
  - Alignment: соответствие действий и убеждений
  - Ретроспектива: на смертном одре буду ли я жалеть?

• Прокрастинация (Procrastination) — крадёт время:
  - Откладывание важного на потом
  - "Завтра начну" → завтра никогда не наступает
  - Страх, перфекционизм как причины
  - Результат: потерянные годы, нереализованные мечты

• Отвлечения (Distractions) — крадут время:
  - Соцсети, бессмысленный сёрфинг, телевизор
  - "Пожиратели времени" без ценности
  - Иллюзия продуктивности (занят, но не результативен)
  - Восстановление внимания: каждое переключение стоит времени

• Сожаления (Regrets) — отравляют время:
  - Зацикливание на прошлом
  - "Если бы я тогда..."
  - Паралич: вместо действий сейчас → думаю о прошлом
  - Прощение себя, отпускание

• Принятие старения (Acceptance of Aging):
  - Старость неизбежна (если повезёт дожить)
  - Каждый возраст имеет свою красоту, возможности
  - Сопротивление старению = страдание
  - Мудрость приходит с возрастом (trade-off за молодость тела)

Восприятие времени в разном возрасте:

ДЕТСТВО (0-12): Время тянется медленно
├─ Каждый день = новые впечатления
├─ Год = огромная доля жизни (1 год из 5 лет = 20%)
└─ Мало рутины, много открытий

МОЛОДОСТЬ (13-30): Время ускоряется
├─ Новые этапы: школа, университет, первая работа, отношения
├─ Много энергии, возможностей
├─ Но начинается рутина
└─ Иллюзия бесконечного времени ("я успею")

ЗРЕЛОСТЬ (30-60): Время летит
├─ Высокая рутинность (работа, семья, быт)
├─ Год = малая доля жизни (1 год из 40 = 2.5%)
├─ Меньше новых впечатлений
└─ Осознание: времени меньше, чем казалось

СТАРОСТЬ (60+): Время субъективно короткое, но ценное
├─ Осознание конечности острое
├─ Мудрость: понимание, что важно
├─ Физические ограничения, но свобода от многих забот
└─ ЕСЛИ прожил хорошо → спокойствие, ИНАЧЕ → сожаления

│  [3] АЛГОРИТМ/БЛОК-СХЕМА — обобщённая теорема, пошаговый процесс         │
└────────────────────────────────────────────────────────────────────────────┘

АЛГОРИТМ ОСМЫСЛЕННОГО ПРОЖИВАНИЯ ВРЕМЕНИ

Шаг 1: ОСОЗНАНИЕ ЦЕННОСТИ ВРЕМЕНИ

РАСЧЁТ ОСТАВШЕГОСЯ ВРЕМЕНИ:
├─ Средняя продолжительность жизни: ~80 лет = 29,200 дней
├─ Твой возраст сейчас: X лет
├─ Оставшееся время (примерно): (80 - X) × 365 дней
├─ Визуализация:
│  └─ Представь 29,200 точек (дней жизни)
│  └─ Вычеркни X × 365 (уже прожитые)
│  └─ Что осталось? Не так много, как кажется
└─ Каждая точка = день, который больше не вернётся

MEMENTO MORI (Помни о смерти):
├─ НЕ для депрессии, а для осознанности
├─ Стоики практиковали ежедневно
├─ Вопрос: "Если бы это был последний день, как бы я его прожил?"
├─ Не откладывать важное ("когда-нибудь потом")
└─ Ценить каждый момент (особенно с близкими)

Шаг 2: АУДИТ ВРЕМЕНИ

ГДЕ УХОДИТ ВРЕМЯ? (отследить неделю):
├─ Записывать все активности (хотя бы примерно):
│  ├─ Работа: X часов
│  ├─ Сон: Y часов  
│  ├─ Еда, быт: Z часов
│  ├─ Семья, друзья: A часов
│  ├─ Хобби, развитие: B часов
│  ├─ Соцсети, ТВ, развлечения: C часов
│  └─ Пустая трата (прокрастинация): D часов
├─ Анализ:
│  ├─ Что занимает больше всего времени?
│  ├─ Соответствует ли это моим ценностям?
│  ├─ ЕСЛИ трачу 3 часа в день на соцсети, но говорю "нет времени на спорт"
│  │  └─ ТО проблема не в отсутствии времени, а в приоритетах
│  └─ Где утечки? Что можно убрать/сократить?
└─ Еженедельный/ежемесячный пересмотр

Шаг 3: ОПРЕДЕЛЕНИЕ ПРИОРИТЕТОВ

МАТРИЦА ЭЙЗЕНХАУЭРА:
┌─────────────────┬─────────────────┐
│  1. ВАЖНОЕ И    │  2. ВАЖНОЕ, НО  │
│     СРОЧНОЕ     │     НЕ СРОЧНОЕ  │
│                 │                 │
│ Кризисы, дедлай │ Планирование,   │
│ ны, проблемы    │ развитие, спорт │
│ Делать СРАЗУ    │ ПЛАНИРОВАТЬ     │
├─────────────────┼─────────────────┤
│ 3. НЕВАЖНОЕ, НО │ 4. НЕВАЖНОЕ И   │
│    СРОЧНОЕ      │    НЕ СРОЧНОЕ   │
│                 │                 │
│ Прерывания,     │ Пустая трата,   │
│ звонки, письма  │ соцсети, ТВ     │
│ ДЕЛЕГИРОВАТЬ    │ УДАЛИТЬ         │
└─────────────────┴─────────────────┘

ПРИОРИТИЗАЦИЯ:
├─ Квадрант 1: Неизбежен, но стремиться минимизировать (кризисы = плохое планирование)
├─ Квадрант 2: САМЫЙ ВАЖНЫЙ (но откладывается, т.к. не срочно)
│  └─ Отношения, здоровье, обучение, личностный рост, долгосрочные цели
│  └─ Выделять время РЕГУЛЯРНО (иначе не случится)
├─ Квадрант 3: Создаёт иллюзию занятости (срочно, но не важно)
│  └─ Учиться говорить "нет", делегировать
└─ Квадрант 4: Убрать максимально
   └─ Отдых ≠ пустая трата (Netflix 3 часа = пустая трата, прогулка = отдых)

ОПРЕДЕЛИТЬ ЛИЧНЫЕ ЦЕННОСТИ:
├─ Что для меня важнее всего? (семья, здоровье, творчество, служение, познание?)
├─ На смертном одре: о чём буду жалеть, если не сделаю?
├─ Записать топ-5 ценностей
└─ Проверить: тратится ли время на эти ценности?

Шаг 4: ЗАЩИТА ВРЕМЕНИ

УСТАНОВИТЬ ГРАНИЦЫ:
├─ Рабочее время: чёткие границы (не работать 24/7)
├─ Время для семьи: защищённое (нельзя отменить)
├─ Время для себя: регулярное (хобби, спорт, развитие)
├─ Научиться говорить "нет":
│  └─ ЕСЛИ предложение не соответствует приоритетам
│     └─ ТО вежливо отказать (не оправдываться, просто "нет, спасибо")
└─ "Нет" второстепенному = "да" главному

УБРАТЬ ПОЖИРАТЕЛЕЙ ВРЕМЕНИ:
├─ Соцсети:
│  ├─ Удалить приложения с телефона (доступ только с компьютера)
│  ├─ Установить лимиты (макс 30 минут в день)
│  └─ Отключить уведомления
├─ Телевизор / Стриминг:
│  ├─ Осознанный выбор (конкретный фильм), а не "залипание"
│  └─ Правило: не включать "для фона"
├─ Новости:
│  ├─ Сократить потребление (1 раз в день, а не постоянно)
│  └─ 90% новостей = шум, не влияют на твою жизнь
└─ Бессмысленные встречи, обязательства:
   └─ Пересмотреть, что можно убрать

СОЗДАТЬ СИСТЕМЫ:
├─ Рутины: утренняя, вечерняя (автоматизация решений)
├─ Time blocking: выделить блоки времени для задач
├─ Правило 2 минут: если задача < 2 минут → сделать сразу
└─ Batching: группировать похожие задачи (отвечать на письма раз в день, а не каждые 5 минут)

Шаг 5: ПРИСУТСТВИЕ В МОМЕНТЕ (Mindfulness)

ПРАКТИКА ОСОЗНАННОСТИ:
├─ Медитация (10-20 минут в день):
│  └─ Фокус на дыхании, наблюдение за мыслями
│  └─ Тренировка присутствия
├─ Однозадачность (Single-tasking):
│  ├─ Делать одно дело за раз (не многозадачность)
│  ├─ ЕСЛИ ешь → ешь (не листай телефон)
│  ├─ ЕСЛИ с другом → слушай (не отвлекайся)
│  └─ Качество > количество
├─ Замечать момент:
│  └─ Несколько раз в день: остановиться, заметить (звуки, запахи, ощущения)
│  └─ "Где я? Что чувствую? Жив ли я по-настоящему СЕЙЧАС?"
└─ Благодарность:
   └─ Вечером: записать 3 вещи, за которые благодарен сегодня

ИЗБЕГАТЬ "ЖИЗНИ ПОТОМ":
├─ НЕ: "Когда заработаю миллион, тогда буду счастлив"
├─ НЕ: "Когда выйду на пенсию, тогда начну жить"
├─ НЕ: "Когда дети вырастут, тогда займусь собой"
├─ ДА: "Счастье сейчас, в процессе, а не в будущей точке"
└─ Цели важны, но путь = сама жизнь

Шаг 6: ЗАМЕДЛЕНИЕ ВРЕМЕНИ

НОВЫЕ ВПЕЧАТЛЕНИЯ:
├─ Мозг запоминает новое ярче → время кажется длиннее
├─ Рутина → дни сливаются → время летит
├─ Способы:
│  ├─ Путешествия (новые места)
│  ├─ Новые хобби (учить язык, инструмент, танцы)
│  ├─ Новые маршруты (ходить на работу разными путями)
│  ├─ Новые люди (знакомства, общение)
│  └─ Эксперименты (пробовать новое регулярно)
└─ Эффект: год с новыми впечатлениями > 10 лет рутины

РИТУАЛЫ И ТРАДИЦИИ:
├─ Создают структуру времени
├─ Делают моменты запоминающимися
├─ Примеры:
│  ├─ Семейный ужин каждую пятницу
│  ├─ Ежегодный отпуск в одно место (ностальгия, преемственность)
│  └─ Утренний кофе в любимой кружке
└─ Ритуалы = якоря во времени

Шаг 7: ПРИНЯТИЕ СТАРЕНИЯ

КАЖДЫЙ ВОЗРАСТ ИМЕЕТ ЦЕННОСТЬ:
├─ Молодость: энергия, открытия, становление
├─ Зрелость: достижения, стабильность, продуктивность
├─ Старость: мудрость, перспектива, свобода от гонки
└─ Не цепляться за молодость (принять изменения)

ИНВЕСТИРОВАТЬ В БУДУЩЕЕ СЕБЯ:
├─ Здоровье: сейчас заботиться → в старости качество жизни
├─ Финансы: копить, инвестировать → финансовая свобода позже
├─ Отношения: укреплять → в старости не быть одиноким
├─ Навыки, знания: учиться всю жизнь → интересная старость
└─ "Лучшее время посадить дерево было 20 лет назад. Следующее лучшее — сейчас."

НЕ БОЯТЬСЯ СМЕРТИ:
├─ Смерть = естественная часть жизни
├─ Страх смерти → паралич жизни
├─ Принятие смерти → свобода жить полно
└─ "Смерть не страшна тому, кто хорошо прожил жизнь"

Шаг 8: РЕГУЛЯРНЫЙ ПЕРЕСМОТР

ЕЖЕМЕСЯЧНАЯ РЕФЛЕКСИЯ:
├─ Как я провёл этот месяц?
├─ Было ли время потрачено на важное?
├─ Что я хочу изменить в следующем месяце?
└─ Корректировка курса

ЕЖЕГОДНЫЙ ОБЗОР:
├─ Что было главным в этом году?
├─ Чему я научился?
├─ О чём жалею? (чтобы не повторить)
├─ Что хочу в следующем году?
└─ Планирование (но гибкое)

КОНТЕКСТ И ПРОИСХОЖДЕНИЕ

Популярная фраза "Time is money" (Время — деньги) приписывается Бенджамину Франклину
(1748, эссе "Advice to a Young Tradesman").

Контекст: Франклин советовал предпринимателям ценить время, потому что время,
потраченное впустую, = упущенная прибыль.

НО: Эта фраза часто понимается неправильно и ведёт к ошибочному отношению ко времени.

Правильное понимание: Время НЕ равно деньгам. Время ДОРОЖЕ денег, потому что:
- Деньги можно заработать снова
- Время невосполнимо

═══════════════════════════════════════════════════════════════════════════════

ОБЪЯСНЕНИЕ

Почему "время = деньги" — опасная метафора:

1. ДЕНЬГИ ВОСПОЛНИМЫ, ВРЕМЯ — НЕТ

   Деньги:
   - Потерял $1000 → можно заработать снова
   - Можно накопить, инвестировать, приумножить
   - Есть всегда "следующая возможность"
   
   Время:
   - Потерял год → никогда не вернёшь
   - Нельзя накопить (нельзя "отложить" сегодняшний день на потом)
   - Каждая минута уходит безвозвратно
   
   Следовательно: время >> деньги (время бесконечно ценнее).

2. ОШИБКА: ТОРГОВАТЬ ВРЕМЕНЕМ ЗА ДЕНЬГИ БЕЗДУМНО

   Если "время = деньги", логика:
   - Продавать всё время за максимальную зарплату
   - Работать 80 часов в неделю (больше денег!)
   - Жертвовать здоровьем, семьёй, отдыхом ради заработка
   
   Результат:
   - Заработал миллионы, но потерял здоровье → деньги на лечение
   - Заработал много, но дети выросли без отца → не купишь потерянное время
   - Заработал состояние, но в 60 лет понял: жизнь прошла мимо
   
   Парадокс: разбогател в деньгах, обеднел во времени.

3. ПРАВИЛЬНАЯ ЛОГИКА: ДЕНЬГИ — ИНСТРУМЕНТ ПОКУПКИ ВРЕМЕНИ

   Не "время → деньги", а "деньги → время":
   
   - Заработать достаточно, чтобы КУПИТЬ свободное время
   - Делегировать (уборка, рутина) → освободить время для важного
   - Не гнаться за максимальным доходом, а найти баланс (достаточно денег + время)
   - Financial Independence: накопить, чтобы не продавать время

4. КАЧЕСТВО ВРЕМЕНИ ≠ КОЛИЧЕСТВО ДЕНЕГ

   Можно быть богатым и несчастным:
   - Миллионер, работающий 100 часов в неделю, в стрессе
   - Нет времени на семью, друзей, себя
   - На смертном одре: "Зачем мне эти деньги?"
   
   Можно быть умеренно обеспеченным и счастливым:
   - Достаточно денег для комфорта
   - Баланс работы и жизни
   - Время на важное: отношения, хобби, здоровье

5. "ВРЕМЯ ДОРОЖЕ ДЕНЕГ" → ПРИОРИТИЗАЦИЯ

   Принятие решений:
   - Не "сколько заплатят?", а "сколько времени отнимут?"
   - Не "самая высокая зарплата", а "лучшее соотношение денег и времени"
   - Тратить деньги, чтобы сэкономить время (такси vs общественный транспорт, 
     если время важнее денег в данный момент)

ПРИМЕРЫ ПРИМЕНЕНИЯ

ПРИМЕР 1: Два пути — максимальный доход vs баланс

ПЕРСОНАЖ А: Алексей, инвестиционный банкир
• Зарплата: $500,000/год
• Рабочее время: 80-100 часов в неделю
• Жизнь: нет времени на семью, спорт, друзей, хобби
• Здоровье: стресс, бессонница, проблемы с сердцем к 40 годам
• В 45: инфаркт, ранняя смерть
• Деньги остались детям, но отца они не видели

ПЕРСОНАЖ Б: Борис, учитель
• Зарплата: $50,000/год (в 10 раз меньше!)
• Рабочее время: 40 часов в неделю + летние каникулы
• Жизнь: время на семью, спорт, чтение, путешествия
• Здоровье: хорошее, активный образ жизни
• Дети: выросли с любящим, присутствующим отцом
• В 70: здоровый, счастливый, богатые воспоминания

ВОПРОС: Кто богаче?
- По деньгам: Алексей
- По жизни: Борис

УРОК: Алексей думал "время = деньги", продал всё время.
Борис понял "время дороже денег", выбрал баланс.

ПРИМЕР 2: Покупка времени деньгами

СИТУАЦИЯ: Мария, фрилансер, зарабатывает $50/час

ВЫБОР 1: Уборка квартиры
- Вариант А: сама (3 часа, $0)
- Вариант Б: нанять уборщицу ($30, 3 часа свободны)

ЕСЛИ "время = деньги":
- Вариант А: потеря 3 часов = $150 упущенной прибыли
- Вариант Б: $30 за уборку + 3 часа можно работать = $150 - $30 = $120 прибыль
- Логично: нанять уборщицу

НО ЕСЛИ "время дороже денег":
- Вопрос: что я хочу делать в эти 3 часа?
- Работать ещё? (выгорание, нет жизни)
- Или провести с ребёнком, отдохнуть, почитать? (бесценно)
- Решение: нанять уборщицу, НО использовать время не для работы, а для жизни

УРОК: Деньги — инструмент покупки времени, но не для того, чтобы работать ещё больше,
а чтобы ЖИТЬ.

ПРИМЕР 3: Выбор работы

ПРЕДЛОЖЕНИЕ 1:
• Компания А: $150,000/год
• 60 часов в неделю, высокий стресс, токсичная среда
• Долгая дорога (2 часа в день)

ПРЕДЛОЖЕНИЕ 2:
• Компания Б: $100,000/год
• 40 часов в неделю, здоровая культура, интересные задачи
• Близко к дому (20 минут)

РАСЧЁТ ПО "ВРЕМЯ = ДЕНЬГИ":
• Компания А: $50,000 больше → выбрать!

РАСЧЁТ ПО "ВРЕМЯ ДОРОЖЕ ДЕНЕГ":
• Компания А: +20 часов работы + 10 часов дороги = 30 часов/неделю потеряно
  - Это 1560 часов/год = 65 полных дней!
  - $50,000 ÷ 1560 часов = $32/час (фактически)
  - Цена: здоровье, отношения, счастье
• Компания Б: баланс, время на жизнь
  - Меньше денег, но больше ЖИЗНИ

ВЫБОР: зависит от приоритетов, но многие выбирают А и жалеют.

ПРИМЕР 4: На смертном одре — сожаления

ИССЛЕДОВАНИЕ: Бронни Вэр, "5 главных сожалений умирающих"

Топ-2 сожаление: "Жаль, что так много работал"

ИСТОРИЯ (типичная):
• Джон, 75 лет, умирает от рака
• Успешная карьера, заработал миллионы
• Дети выросли, почти не знают отца (он всегда работал)
• Жена: развелась 20 лет назад (не выдержала одиночества)
• Друзья: потерял связь (не было времени)
• Последние слова: "Я потратил жизнь на зарабатывание денег, 
  которые мне теперь не нужны. Я бы отдал всё, чтобы вернуть время с семьёй."

УРОК: На смертном одре никто не говорит "Жаль, что мало заработал".
Говорят: "Жаль, что мало жил, мало любил, мало был с близкими."

"Время = деньги" → ловушка.
"Время дороже денег" → мудрость.

СВЯЗЬ С ФОРМУЛОЙ

Эта теорема связана с формулой:

L = T × Q

где:
- T (Time) — ограниченный ресурс
- Q (Quality) — как используешь время

Если думаешь "время = деньги":
- Максимизируешь T для заработка → Q страдает (низкое качество жизни)
- L (ценность жизни) = низкая, даже при высоком доходе

Если понимаешь "время дороже денег":
- Баланс: достаточно денег + высокое Q (качество использования времени)
- L (ценность жизни) = высокая

Деньги влияют на формулу, но НЕ главный фактор. Q важнее.

ПРАКТИЧЕСКИЕ СОВЕТЫ

1. ПЕРЕСМОТРЕТЬ ОТНОШЕНИЕ К ЗАРАБОТКУ

   ✓ НЕ "максимум денег", а "достаточно денег + баланс"
   ✓ Определить: сколько нужно для комфорта? (больше не обязательно лучше)
   ✓ Закон убывающей отдачи: $50k→$100k = большая разница в счастье,
     $200k→$300k = малая разница

2. ПОКУПАТЬ ВРЕМЯ, А НЕ ВЕЩИ

   ✓ Тратить деньги на то, что освобождает время:
     - Делегировать рутину (уборка, готовка, если позволяют деньги)
     - Жить ближе к работе (дорога = потерянное время)
     - Автоматизировать, упрощать
   ✓ Меньше вещей, больше впечатлений (путешествия > новый телевизор)

3. СЧИТАТЬ СТОИМОСТЬ В ЧАСАХ ЖИЗНИ

   ✓ Перевести покупку в часы работы:
     - Новая машина за $30,000, зарплата $30/час = 1000 часов работы
     - 1000 часов = 125 рабочих дней = полгода жизни
     - Стоит ли эта машина полгода жизни?
   ✓ Осознанное потребление

4. НЕ ОТКЛАДЫВАТЬ ЖИЗНЬ

   ✓ НЕ "когда заработаю/выйду на пенсию, тогда буду жить"
   ✓ ДА "жить сейчас, каждый день"
   ✓ Баланс: работа для жизни, а не жизнь для работы

5. ВРЕМЯ С БЛИЗКИМИ = БЕСЦЕННО

   ✓ Не жертвовать семьёй, друзьями ради денег
   ✓ Воспоминания о проведённом времени > материальные блага
   ✓ Дети вырастут, родители состарятся — время не вернуть

6. FINANCIAL INDEPENDENCE (финансовая независимость)

   ✓ Цель: накопить достаточно, чтобы не продавать время
   ✓ FIRE движение (Financial Independence, Retire Early)
   ✓ Жить скромно, копить, инвестировать → свобода времени раньше

КОГДА ТЕОРЕМА НЕ РАБОТАЕТ

⚠ Крайняя бедность:
  - Если еле сводишь концы с концами, приходится продавать время за любые деньги
  - Роскошь выбора "баланса" недоступна
  - НО: даже тогда искать способы оптимизации, образование, выход из ситуации

⚠ Краткосрочные периоды интенсивной работы:
  - Стартап, важный проект — временно работать больше
  - ЕСЛИ это осознанный выбор И временно — ок
  - Опасность: "временно" растягивается на десятилетия

⚠ Любовь к работе:
  - ЕСЛИ работа = призвание, источник радости (не стресс)
  - ТО работать много может быть осмысленно
  - НО: баланс всё равно нужен (здоровье, отношения)

ДОПОЛНИТЕЛЬНЫЕ АФОРИЗМЫ НА ТЕМУ ВРЕМЕНИ

• "Время лечит" — боль, потери со временем становятся легче

• "Делу время, потехе час" — баланс работы и отдыха

• "Не откладывай на завтра то, что можешь сделать сегодня" — 
  борьба с прокрастинацией

• "Лучшее время посадить дерево было 20 лет назад. Следующее лучшее — сейчас" —
  никогда не поздно начать

• "Время покажет" — истина проявляется со временем

• "Счастливые часов не наблюдают" (Грибоедов) — когда счастлив, время летит
