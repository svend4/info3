# Образование — Формулы знания и обучения

## 📚 Базовые формулы образования

**Образование:**
```
Образование = Знания + Навыки + Мышление + Ценности
Ed = Kn + Sk + Th + Va
```

**Обучение:**
```
Обучение = Информация × Понимание × Практика
Le = In × Un × Pr
```

**Знание:**
```
Знание = Информация × Контекст × Опыт
K = I × Co × Ex
```

**Мудрость:**
```
Мудрость = Знание × Опыт / Эго
Wi = K × Ex / Eg
```

## 🎓 Формулы процесса обучения

**Кривая обучения:**
```
Навык(t) = A × (1 - e^(-kt))
рост к асимптоте
```

**Правило 10,000 часов:**
```
Мастерство = 10,000 часов × Качество_практики
Ma = 10k_h × Q_practice
```

**Зона ближайшего развития (Выготский):**
```
Обучение_оптимальное = Знаю + (Помощь × Вызов)
Le_optimal = Know + (Help × Challenge)
```

**Активное обучение:**
```
Запоминание = Активность × Вовлечённость
Re = Activity × Engagement
пассивное < активное
```

## 🧠 Формулы памяти

**Кривая забывания Эббингауза:**
```
R(t) = e^(-t/S)
где S — сила памяти
```

**Интервальное повторение:**
```
Интервал_n+1 = Интервал_n × k
где k = 2-3
оптимальное повторение
```

**Эффект интервала:**
```
Запоминание ∝ √(Интервалы_между_повторениями)
```

**Долговременная память:**
```
LTM = STM × Повторение × Значимость × Эмоция
```

## 📖 Формулы чтения

**Понимание текста:**
```
Понимание = Словарь × Контекст × Фоновые_знания
Un = Vo × Co × Ba_knowledge
```

**Скорость чтения:**
```
Скорость = Слов_в_минуту
Speed = WPM
средняя: 200-300 WPM
```

**Усвоение:**
```
Усвоение = Чтение × Размышление × Применение
As = Re × Th × Ap
```

**Критическое чтение:**
```
Критика = Понимание × Анализ × Оценка
Cr = Un × An × Ev
```

## 🎯 Формулы мотивации к обучению

**Мотивация:**
```
Мотивация = (Ценность × Ожидание) - (Усилия + Задержка)
Mo = (Va × Ex) - (Ef + De)
```

**Интерес:**
```
Интерес = Новизна + Релевантность + Вызов
In = No + Re + Ch
```

**Любопытство:**
```
Любопытство = Информационный_разрыв × Безопасность
Cu = Info_gap × Sa
```

**Внутренняя мотивация:**
```
Внутренняя > Внешняя (долгосрочно)
Intrinsic > Extrinsic (long-term)
```

## 👨‍🏫 Формулы преподавания

**Эффективное преподавание:**
```
Эффективность = Ясность × Вовлечённость × Обратная_связь
Ef = Cl × En × Fe
```

**Соотношение учитель-ученик:**
```
Внимание_индивидуальное ∝ 1/Число_учеников
At_individual ∝ 1/N_students
```

**Объяснение:**
```
Объяснение = Простота × Примеры × Аналогии
Ex = Si × Ex × An
```

**Сократовский метод:**
```
Обучение = Вопросы > Ответы
Le = Questions > Answers
```

**Формативное vs Суммативное:**

Суммативное: в конце
оба важны

**Обратная связь:**

Im = Feedback × Application

## 📈 Формулы прогресса

**Прогресс в обучении:**
```
Прогресс = (Знания_сейчас - Знания_начало) / Время
Pr = (K_now - K_start) / T
```

**Кривая мастерства:**
```
Мастерство = Новичок → Продвинутый → Эксперт → Мастер
Ma = Novice → Advanced → Expert → Master
```

**Плато:**
```
∃ периоды: Прогресс ≈ 0
есть плато перед прорывом
```

**Прорыв:**
```
Прорыв = Накопление × Триггер
Br = Accumulation × Trigger
```

## 🎯 Формулы целей обучения

**SMART цели:**
```
Цель = Конкретная × Измеримая × Достижимая × Релевантная × Ограниченная_временем
Go = Sp × Me × Ac × Re × Ti
```

**Мастерство vs Производительность:**
```
Мастерство: фокус на обучение
Производительность: фокус на результат
Mastery > Performance (долгосрочно)
```

**Промежуточные цели:**
```
Большая_цель = ∑(Маленькие_цели_i)
Bi_goal = ∑(Sm_goals_i)
```

**Обучение на протяжении жизни:**
```
Знания(t) = ∫(Обучение) dt от 0 до ∞

```

## 🏫 Формулы систем образования

**Качество образования:**
```
Качество = Учителя × Программа × Ресурсы × Среда
Q = Te × Cu × Re × En
```

**Доступность:**
```
Доступность = (Мест × Качество) / (Стоимость × Барьеры)
Ac = (Pl × Q) / (Co × Ba)
```

**ROI образования:**
```
ROI = (Будущий_доход - Текущий_доход - Стоимость) / Стоимость
```

**Социальная мобильность:**
```
Мобильность ∝ Образование
Mo ∝ Ed
образование — лифт
```
