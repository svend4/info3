│ [1] ФОРМУЛА — Математическая абстракция                                    │

Convolution (свёртка) — основа CNN:
(I * K)[i,j] = ΣΣ I[i+m, j+n] × K[m,n]

где:
I — входное изображение
K — kernel (фильтр)
* — операция свёртки

→ Свёртка извлекает features (edges, textures, patterns)

Receptive Field (рецептивное поле):
RF = 1 + Σ((kernel_size - 1) × stride^layer)

→ Какую область исходного изображения "видит" каждый нейрон

ImageNet Top-5 Error Rate (прогресс CV):
• 2010: 28% (traditional CV)
• 2012: 16% (AlexNet — прорыв deep learning)
• 2015: 3.5% (ResNet)
• 2024: <1% (ViT, EfficientNet)

Человек: ~5% error rate
→ AI превзошёл человека в классификации ImageNet

Intersection over Union (IoU) — метрика object detection:
IoU = Area_of_Overlap / Area_of_Union

→ IoU > 0.5 обычно считается "правильным" детектированием

Precision vs Recall:
Precision = TP / (TP + FP)  — точность
Recall = TP / (TP + FN)     — полнота

mAP (mean Average Precision) — стандартная метрика для object detection

Computer Vision = (Input × Architecture) × (Tasks × Applications) × (Challenges)

Компоненты:

Input (Вход):
├─ Images:
│  ├─ RGB: 3 канала (Red, Green, Blue)
│  ├─ Grayscale: 1 канал
│  ├─ Multispectral: >3 каналов (медицина, спутники)
│  └─ Depth: RGB-D (RGB + Depth от камеры)
├─ Video:
│  ├─ Sequences of frames
│  ├─ Temporal information: движение объектов
│  └─ Optical flow: направление движения пикселей
├─ 3D:
│  ├─ Point clouds: LiDAR данные
│  ├─ Voxels: 3D пиксели
│  └─ Meshes: треугольники, вершины
└─ Medical:
   ├─ CT scans: компьютерная томография
   ├─ MRI: магнитно-резонансная томография
   ├─ X-rays: рентген
   └─ Microscopy: клетки, ткани

Architecture (Архитектуры):

Classical CV (до deep learning):
├─ Edge detection: Sobel, Canny
├─ Feature extraction: SIFT, SURF, HOG
├─ Template matching: корреляция
└─ Haar cascades: лица (Viola-Jones)

Convolutional Neural Networks (CNN):
├─ LeNet (1998): распознавание цифр MNIST
├─ AlexNet (2012): ImageNet прорыв
│  └─ 8 layers, ReLU, dropout, GPU training
├─ VGG (2014): deeper networks (16-19 layers)
│  └─ 3x3 convolutions, простая архитектура
├─ GoogLeNet/Inception (2014): multi-scale features
│  └─ Inception modules: параллельные свёртки
├─ ResNet (2015): residual connections
│  └─ Skip connections: решает vanishing gradient
│  └─ 50, 101, 152 слоя — очень глубокие сети
├─ DenseNet: каждый слой подключен ко всем предыдущим
├─ MobileNet: эффективные CNN для мобильных
│  └─ Depthwise separable convolutions
├─ EfficientNet: compound scaling (width, depth, resolution)
└─ Vision Transformer (ViT, 2020): attention вместо convolutions
   └─ Разбивает изображение на patches, применяет transformer

Object Detection:
├─ R-CNN family (2014-2017):
│  ├─ R-CNN: region proposals + CNN
│  ├─ Fast R-CNN: faster region pooling
│  └─ Faster R-CNN: Region Proposal Network
├─ YOLO (You Only Look Once):
│  ├─ Single-shot detector: вся картинка за раз
│  ├─ YOLOv1 (2015) → YOLOv8 (2023)
│  └─ Real-time: 30-60 FPS
├─ SSD (Single Shot Detector): multi-scale features
└─ DETR (2020): transformer for detection

Semantic Segmentation:
├─ FCN (Fully Convolutional Network): pixel-wise classification
├─ U-Net: encoder-decoder с skip connections (медицина)
├─ DeepLab: atrous convolutions, CRF
└─ Mask R-CNN: instance segmentation (каждый объект отдельно)

Generative Models:
├─ GAN (Generative Adversarial Networks):
│  ├─ Generator: создаёт изображения
│  ├─ Discriminator: отличает реальное от фейка
│  ├─ StyleGAN: реалистичные лица
│  └─ CycleGAN: image-to-image translation
├─ VAE (Variational Autoencoder): probabilistic generation
└─ Diffusion Models:
   ├─ Stable Diffusion: text-to-image
   ├─ DALL-E 2/3: OpenAI multimodal
   └─ Midjourney: художественная генерация

Tasks (Задачи):

1. Image Classification:
   • Что на изображении? (кошка, собака, самолёт)
   • Single label или multi-label
   • Fine-grained: породы собак, виды птиц

2. Object Detection:
   • Где объекты? Bounding boxes + классы
   • Real-time: автономные машины, видеонаблюдение
   • Multi-scale: маленькие и большие объекты

3. Semantic Segmentation:
   • Pixel-wise classification
   • Каждый пиксель → класс (дорога, небо, машина)
   • Применение: автономное вождение

4. Instance Segmentation:
   • Semantic + разделение экземпляров
   • Каждый объект отдельная маска
   • Пример: 3 человека → 3 разные маски

5. Face Recognition:
   • Identification: кто это? (1:N matching)
   • Verification: это тот же человек? (1:1)
   • Face detection + feature extraction + matching
   • Applications: security, phone unlock, social media tagging

6. Pose Estimation:
   • Keypoint detection: суставы, лицевые landmarks
   • 2D: координаты на изображении
   • 3D: трёхмерная поза
   • Applications: спорт анализ, AR, gaming

7. Optical Character Recognition (OCR):
   • Текст из изображений
   • Scene text: дорожные знаки, вывески
   • Document OCR: сканы, счета, квитанции
   • Handwriting recognition: рукописный текст

8. Image Captioning:
   • Генерация описания изображения
   • Encoder (CNN) → Decoder (RNN/Transformer)
   • "A dog playing with a ball in the park"

9. Visual Question Answering (VQA):
   • Image + Question → Answer
   • "How many people are in the image?"
   • Multimodal: vision + language

10. 3D Reconstruction:
    • 2D images → 3D model
    • Structure from Motion (SfM)
    • Neural Radiance Fields (NeRF)
    • Applications: VR/AR, robotics

Applications (Применения):

Automotive:
├─ Autonomous driving: Tesla, Waymo, Cruise
├─ Lane detection: удержание полосы
├─ Traffic sign recognition: знаки, светофоры
├─ Pedestrian detection: безопасность
└─ Parking assistance: камеры вокруг автомобиля

Medical:
├─ Radiology: X-ray, CT, MRI analysis
├─ Pathology: гистологические срезы
├─ Retinopathy: диабетическая ретинопатия
├─ Tumor detection: рак, опухоли
└─ Surgical assistance: guided surgery

Security:
├─ Surveillance: детекция подозрительной активности
├─ Face recognition: access control, law enforcement
├─ Anomaly detection: необычное поведение
└─ Weapon detection: автоматическое обнаружение

Retail:
├─ Checkout-free stores: Amazon Go
├─ Visual search: поиск по фото (Google Lens)
├─ Inventory management: автоматический подсчёт товаров
└─ Virtual try-on: AR примерка одежды

Agriculture:
├─ Crop monitoring: здоровье растений
├─ Pest detection: насекомые, болезни
├─ Yield prediction: оценка урожая
└─ Autonomous farming: роботы-комбайны

Manufacturing:
├─ Quality control: дефекты на производстве
├─ Assembly verification: правильность сборки
├─ Robot guidance: bin picking, welding
└─ Predictive maintenance: износ оборудования

Entertainment:
├─ Face filters: Snapchat, Instagram
├─ Motion capture: фильмы, игры
├─ Content moderation: NSFW detection
└─ Video editing: automatic highlights

Challenges (Вызовы):

Technical:
├─ Occlusion: объекты перекрываются
├─ Illumination: освещение меняется
├─ Viewpoint: разные углы обзора
├─ Scale: объекты разных размеров
├─ Background clutter: сложный фон
├─ Class imbalance: редкие классы
├─ Real-time constraints: low latency требуется
└─ Edge cases: необычные ситуации

Data:
├─ Annotation cost: разметка дорога и долга
├─ Bias: тренировочные данные не репрезентативны
├─ Privacy: лица, персональная информация
└─ Domain shift: модель на новых данных хуже

Ethics:
├─ Surveillance: mass monitoring
├─ Bias: расовая, гендерная дискриминация
├─ Deepfakes: synthetic media для дезинформации
├─ Autonomous weapons: military applications
└─ Job displacement: автоматизация визуальных задач

TRAINING PROCESS:

1. Data Collection: собрать изображения
2. Annotation: разметить (bbox, masks, labels)
3. Data Augmentation: rotation, flip, crop, color jitter
4. Model Selection: ResNet, YOLO, etc.
5. Training:
   • Forward pass: predictions
   • Loss calculation: cross-entropy, IoU loss
   • Backpropagation: gradients
   • Optimizer: SGD, Adam
6. Validation: оценка на val set
7. Hyperparameter tuning: learning rate, architecture
8. Testing: финальная оценка
9. Deployment: production inference

ОБЪЯСНЕНИЕ:

ЧТО AI УМЕЕТ ЛУЧШЕ ЛЮДЕЙ:

1. Image Classification (ImageNet):
   • AI: <1% top-5 error
   • Человек: ~5% error
   • AI может различать 1000 категорий мгновенно

2. Face Recognition:
   • AI: 99.9%+ accuracy (в контролируемых условиях)
   • Лучше людей в matching огромных баз данных
   • Пример: найти лицо среди миллионов фото

3. Medical Imaging (некоторые задачи):
   • Diabetic retinopathy: на уровне офтальмологов
   • Skin cancer: comparable to dermatologists
   • Mammography: некоторые исследования показывают превосходство

4. Repetitive Inspection:
   • Quality control: дефекты на производстве
   • Никогда не устаёт, постоянная точность
   • Обрабатывает тысячи изображений в секунду

ЧТО AI ДЕЛАЕТ ХУЖЕ ЛЮДЕЙ:

1. Context Understanding:
   • AI видит patterns, не "понимает" сцену
   • Пример: может не понять, что человек под зонтом прячется от дождя
   • Common sense reasoning отсутствует

2. Few-shot Learning:
   • Ребёнок видит слона 1 раз → узнаёт всегда
   • AI нужны тысячи примеров
   • (Few-shot learning улучшается, но всё ещё ограничен)

3. Robustness:
   • Adversarial examples: крошечные возмущения → неправильная классификация
   • Humans: устойчивы к шуму, искажениям
   • AI: может сломаться на slightly different conditions

4. Generalization:
   • AI тренирован на ImageNet → плохо на медицинских изображениях
   • Domain shift проблематичен
   • Humans: transfer learning естественен

5. 3D Understanding:
   • Люди легко представляют 3D из 2D
   • AI struggle with 3D reasoning from images
   • (Улучшается с NeRF, но всё ещё сложно)

ПРИМЕРЫ УСПЕХОВ И ПРОВАЛОВ:

УСПЕХ: AlexNet (2012) — ImageNet прорыв
• Top-5 error: 15.3% (vs 26% предыдущий год)
• Доказал, что deep learning работает для CV
• Запустил эру deep learning в CV

УСПЕХ: Face Recognition (китайские системы)
• SenseTime, Megvii: >99% accuracy
• Используется в surveillance, payments
• НО: этические concerns (privacy, government control)

ПРОВАЛ: Autonomous Driving Edge Cases
• Tesla Autopilot аварии:
  - Не распознал белый грузовик на фоне светлого неба (2016)
  - Врезался в перевёрнутый грузовик (2019)
  - Не видел пожарную машину (multiple incidents)
• Причина: edge cases не в training data
• Долгий хвост редких ситуаций — проблема

ПРОВАЛ: Google Photos (2015) — расистская ошибка
• Пометила чернокожих людей как "gorillas"
• Причина: bias в training data (мало разнообразия)
• Google решение: удалить категорию "gorilla" (band-aid fix)
• Показало важность diverse datasets

УСПЕХ: Medical AI — Diabetic Retinopathy
• Google AI: на уровне офтальмологов (2016)
• FDA approval (2018)
• Применение в развивающихся странах (нехватка врачей)
• НО: требует высококачественные изображения, не всегда доступны

ПРОВАЛ: Amazon Rekognition — False Positives
• ACLU test (2018): сравнили конгрессменов с mug shots
• 28 false matches (40% — minorities)
• Показало bias и unreliability для law enforcement
• Amazon временно запретил продажу полиции

УРОК:
CV невероятно мощный для узких, чётко определённых задач с большим количеством данных.
НО: не "видит" как человек, легко ломается на edge cases, имеет biases.

Важно:
• Не переоценивать возможности
• Тестировать на diverse data
• Human-in-the-loop для критических применений
• Осознавать этические импликации

ПРАКТИЧЕСКИЕ РЕКОМЕНДАЦИИ:

1. ДЛЯ РАЗРАБОТЧИКОВ:

   Начало работы:
   • Frameworks: PyTorch, TensorFlow, Keras
   • Pre-trained models: torchvision, timm
   • Datasets: ImageNet, COCO, Pascal VOC
   
   Transfer Learning:
   • Не тренируйте с нуля, используйте pre-trained
   • Fine-tune на своих данных
   • ResNet, EfficientNet как backbone
   
   Data Augmentation:
   • Albumentations library
   • Rotation, flip, crop, color jitter
   • Cutout, mixup для regularization
   
   Debugging:
   • Visualize activations: что видит модель?
   • Grad-CAM: где модель смотрит?
   • Confusion matrix: какие классы путает?

2. ДЛЯ БИЗНЕСА:

   Когда использовать CV:
   ✅ Повторяющиеся визуальные задачи
   ✅ Большие объёмы данных для обработки
   ✅ Нужна скорость/масштаб (humans too slow)
   
   Когда НЕ использовать:
   ❌ Критичные решения без human oversight
   ❌ Мало данных для обучения
   ❌ Высокая стоимость ошибки (false positives/negatives)
   
   ROI расчёт:
   • Стоимость annotation: $0.01-$1 per image
   • Compute: GPU cloud ($1-3/hour)
   • Development time: 3-12 месяцев
   • Vs. human labor cost

3. ДЛЯ ОБЩЕСТВА:

   Privacy concerns:
   • Face recognition: слежка, tracking
   • Opt-out mechanisms
   • Регулирование: EU AI Act, California laws
   
   Bias mitigation:
   • Diverse training data
   • Fairness metrics: equal error rates across demographics
   • Regular audits
   
   Transparency:
   • Explainability: почему модель решила так?
   • Disclosure: когда AI используется?
   • Right to challenge: можно оспорить AI решение

ЗАКЛЮЧЕНИЕ:

Компьютерное зрение прошло путь от простых edge detectors до моделей, 
превосходящих людей в специфических задачах.

КЛЮЧЕВЫЕ ДОСТИЖЕНИЯ:
• ImageNet classification: superhuman accuracy
• Face recognition: 99%+ в контролируемых условиях
• Medical imaging: на уровне экспертов в некоторых задачах
• Real-time object detection: 60+ FPS на видео

НО ОГРАНИЧЕНИЯ ОСТАЮТСЯ:
• Edge cases: редкие ситуации ломают модели
• Bias: отражает предрассудки данных
• Lack of understanding: pattern matching, не reasoning
• Adversarial vulnerability: легко обмануть

БУДУЩЕЕ:
• Multimodal models: vision + language (CLIP, Flamingo)
• 3D understanding: NeRF, Gaussian Splatting
• Few-shot learning: меньше данных нужно
• Embodied AI: роботы с визуальным пониманием

Компьютерное зрение — мощный инструмент, но требует осторожного применения, 
осознания ограничений, и этического использования.

"Видеть — не значит понимать. AI может распознавать, но не обязательно понимает."
