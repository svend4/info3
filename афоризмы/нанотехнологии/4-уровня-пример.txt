Нанометр:
1 nm = 10⁻⁹ m = 0.000000001 метра

Масштаб:
• Волос человека: 80,000-100,000 nm
• Клетка: 10,000-100,000 nm
• Бактерия: 1,000-10,000 nm
• Вирус: 20-400 nm
• ДНК: 2 nm ширина
• Атом: 0.1-0.5 nm

Нанотехнологии: 1-100 nm

Surface Area to Volume Ratio:
SA/V ∝ 1/size

→ При уменьшении размера площадь поверхности растёт относительно объёма
→ Наночастицы: огромная поверхность → высокая реактивность

Quantum Effects:
На наномасштабе работают законы квантовой механики, не классической физики

Properties ≠ f(Material) alone
Properties = f(Material × Size × Shape × Structure)

→ Золото в наноразмере: красное, не жёлтое
→ Углерод: графит (мягкий) vs алмаз (твёрдый) vs графен vs нанотрубки

Nanotechnology = (Materials × Fabrication) × (Characterization × Applications)

Компоненты:

Nanomaterials (Наноматериалы):
├─ Carbon-based:
│  ├─ Graphene: 2D углерод, прочнее стали, проводит электричество
│  ├─ Carbon Nanotubes (CNT): цилиндрические, сверхпрочные
│  ├─ Fullerenes (C60): футбольный мяч из углерода
│  └─ Graphene Oxide: окисленный графен, гидрофильный
├─ Metal-based:
│  ├─ Gold nanoparticles: медицина, катализ, оптика
│  ├─ Silver nanoparticles: антибактериальные свойства
│  ├─ Quantum dots: полупроводниковые нанокристаллы, светятся
│  └─ Platinum/Palladium: катализаторы
├─ Metal Oxide:
│  ├─ TiO2: самоочищающиеся поверхности, солнечные батареи
│  ├─ ZnO: солнцезащитные кремы, электроника
│  └─ Fe2O3: магнитные наночастицы для медицины
└─ Polymeric:
   ├─ Dendrimers: разветвлённые молекулы для доставки лекарств
   ├─ Liposomes: липидные наночастицы для drugs
   └─ Micelles: самособирающиеся структуры

Fabrication (Производство):
├─ Top-down (сверху вниз):
│  ├─ Photolithography: для чипов (EUV: 13.5 nm)
│  ├─ Etching: удаление материала
│  ├─ Milling: механическое удаление
│  └─ Laser ablation: испарение лазером
└─ Bottom-up (снизу вверх):
   ├─ Self-assembly: молекулы сами организуются
   ├─ Chemical synthesis: выращивание наночастиц
   ├─ CVD (Chemical Vapor Deposition): осаждение из газа
   └─ ALD (Atomic Layer Deposition): атомный слой за слоем

Characterization (Исследование):
├─ Microscopy:
│  ├─ SEM (Scanning Electron Microscope): поверхность, до 1 nm
│  ├─ TEM (Transmission EM): внутренняя структура, до 0.05 nm
│  ├─ AFM (Atomic Force Microscope): 3D топография, атомарное разрешение
│  └─ STM (Scanning Tunneling Microscope): атомы индивидуально
├─ Spectroscopy:
│  ├─ XRD (X-Ray Diffraction): кристаллическая структура
│  ├─ Raman: молекулярные колебания
│  ├─ UV-Vis: оптические свойства
│  └─ XPS: химический состав поверхности
└─ Other:
   ├─ DLS (Dynamic Light Scattering): размер частиц
   ├─ BET: площадь поверхности
   └─ Zeta potential: поверхностный заряд

Applications (Применения):

1. Электроника:
   ├─ Полупроводники: чипы 3nm, 5nm, 7nm
   ├─ Дисплеи: OLED, quantum dot дисплеи
   ├─ Батареи: литий-ионные с наноструктурированными электродами
   ├─ Память: наноразмерные транзисторы
   └─ Сенсоры: газовые, биологические

2. Медицина:
   ├─ Drug delivery: таргетированная доставка лекарств к опухолям
   ├─ Imaging: контрастные агенты для МРТ, КТ
   ├─ Diagnostics: biosensors для раннего обнаружения болезней
   ├─ Tissue engineering: наноскаффолды для роста тканей
   └─ Antibacterial: серебряные наночастицы в повязках

3. Энергия:
   ├─ Солнечные батареи: perovskite cells, quantum dots
   ├─ Топливные элементы: катализаторы на наночастицах
   ├─ Батареи: Li-ion с наноматериалами (больше ёмкость)
   ├─ Суперконденсаторы: графеновые электроды
   └─ Термоэлектрики: наноструктуры для генерации из тепла

4. Материалы:
   ├─ Покрытия: самоочищающиеся, антибликовые, гидрофобные
   ├─ Композиты: углеродные нанотрубки для усиления (авиация, спорт)
   ├─ Текстиль: водо/грязеотталкивающие ткани, антибактериальные
   └─ Краски: с наночастицами для долговечности

5. Окружающая среда:
   ├─ Очистка воды: нанофильтры, адсорбенты
   ├─ Катализ: разложение загрязнителей
   ├─ Сенсоры: детекция токсинов
   └─ Remediation: очистка загрязнённых почв

6. Потребительские товары:
   ├─ Косметика: солнцезащитные кремы (ZnO, TiO2 наночастицы)
   ├─ Спортивные товары: лёгкие и прочные (углеродные нанотрубки)
   ├─ Одежда: пятноустойчивая, антибактериальная
   └─ Упаковка: барьерные свойства для пищи

ОБЪЯСНЕНИЕ:

ХАЙП (2000-е):
• "Нанороботы вылечат все болезни!"
• "Молекулярные ассемблеры создадут что угодно!"
• "Космический лифт из углеродных нанотрубок!"

РЕАЛЬНОСТЬ (2024):
• Нанотехнологии УЖЕ повсюду, но незаметно
• Ваш смартфон: чип 3nm — это нанотехнология
• Солнцезащитный крем: наночастицы ZnO
• Одежда: наночастицы для водоотталкивания

НО: Революционные применения всё ещё в будущем
• Таргетированная доставка лекарств: есть, но ограничена
• Нанороботы: в основном научная фантастика
• Молекулярная сборка: далёкое будущее

БАРЬЕРЫ:
• Масштабирование производства
• Стоимость
• Безопасность и токсичность
• Регулирование

Нанотехнологии развиваются медленнее, чем обещали, 
но быстрее, чем замечает общественность.
