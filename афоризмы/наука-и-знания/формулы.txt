# Наука и знания — Фундаментальные формулы

## ⚛️ Физические формулы

**E = mc²** (Эйнштейн)
```
Энергия = Масса × Скорость_света²
E = mc²
```

**F = ma** (Ньютон)
```
Сила = Масса × Ускорение
F = ma
```

**Гравитация:**
```
F = G × (m₁ × m₂) / r²
```

**Квантовая механика:**
```
ΔxΔp ≥ ℏ/2
принцип неопределённости Гейзенберга
```

**Энтропия:**
```
S = k × ln(W)
энтропия растёт
```
