Центральная догма молекулярной биологии:
DNA → RNA → Protein

Геном человека:
• 3 млрд пар оснований (A, T, G, C)
• ~20,000-25,000 генов (кодируют белки)
• 98.5% — некодирующая ДНК (регуляция, структура)

Секвенирование:
Cost per genome = $100 млн (2001, Human Genome Project)
                → $1,000 (2024, Illumina NovaSeq)

Moore's Law: удвоение каждые 2 года
Sequencing cost: уменьшение в 100,000 раз за 20 лет!

Sequence Alignment Score:
Score = Σ (match × reward - mismatch × penalty - gap × penalty)

BLAST E-value:
E = m × n × 2^(-S)

где:
m, n — размеры сравниваемых последовательностей
S — alignment score

→ E-value < 0.05: статистически значимое совпадение

Bioinformatics = (Sequencing × Databases) × (Analysis × ML) × (Applications)

Компоненты:

Sequencing (Секвенирование):
├─ Sanger sequencing: "первое поколение", точный, медленный
├─ Next-Generation Sequencing (NGS):
│  ├─ Illumina: доминирует рынок, короткие чтения (150-300bp)
│  ├─ Ion Torrent: полупроводниковая технология
│  └─ MGI/BGI: китайская альтернатива Illumina
├─ Third-Generation:
│  ├─ PacBio (Pacific Biosciences): длинные чтения (10-100kb), низкая точность
│  ├─ Oxford Nanopore: real-time, портативные устройства
│  └─ Преимущества: длинные чтения решают repeat regions
└─ Applications:
   ├─ Whole Genome Sequencing (WGS): весь геном
   ├─ Exome Sequencing: только coding regions (дешевле)
   ├─ RNA-seq: экспрессия генов
   ├─ ChIP-seq: белок-ДНК взаимодействия
   └─ Single-cell sequencing: индивидуальные клетки

Databases (Базы данных):
├─ Genomic:
│  ├─ GenBank (NCBI): все опубликованные геномы
│  ├─ Ensembl (EBI): аннотированные геномы
│  ├─ UCSC Genome Browser: визуализация
│  └─ 1000 Genomes: вариации у людей
├─ Protein:
│  ├─ UniProt: все известные белки
│  ├─ PDB (Protein Data Bank): 3D структуры белков
│  └─ Pfam: белковые семейства
├─ Literature:
│  ├─ PubMed: медицинские и биологические статьи
│  └─ PubMed Central: full-text статьи
└─ Disease:
   ├─ OMIM: генетические заболевания
   ├─ ClinVar: клинические варианты
   └─ GWAS Catalog: genome-wide association studies

Analysis Tools (Инструменты анализа):
├─ Sequence Alignment:
│  ├─ BLAST: поиск похожих последовательностей
│  ├─ BLAT: быстрее BLAST, для больших геномов
│  ├─ Bowtie/BWA: alignment reads к reference genome
│  └─ Needleman-Wunsch, Smith-Waterman: точные алгоритмы
├─ Variant Calling:
│  ├─ GATK: gold standard для SNP/indel calling
│  ├─ VarScan, FreeBayes: альтернативы
│  └─ Определение мутаций (SNPs, insertions, deletions)
├─ Gene Expression:
│  ├─ DESeq2, edgeR: differential expression analysis
│  ├─ Находит гены, которые up/down regulated
│  └─ RNA-seq analysis
├─ Phylogenetics:
│  ├─ MEGA: построение эволюционных деревьев
│  ├─ RAxML: maximum likelihood trees
│  └─ Изучение эволюционных связей
└─ Genome Assembly:
   ├─ SPAdes, Velvet: собирают геном из коротких чтений
   ├─ Canu, Flye: для длинных чтений
   └─ De novo assembly: без reference genome

Machine Learning в биоинформатике:
├─ Sequence Prediction:
│  ├─ Gene finding: где начинаются/заканчиваются гены
│  ├─ Splice site prediction: intron/exon границы
│  └─ Promoter detection: regulatory regions
├─ Protein Structure Prediction:
│  ├─ AlphaFold (DeepMind): революция в предсказании структуры
│  ├─ RoseTTAFold: альтернатива от Baker lab
│  └─ Решена 50-летняя проблема protein folding
├─ Drug Discovery:
│  ├─ Molecule generation: AI создаёт кандидаты
│  ├─ Binding affinity prediction: как сильно связывается
│  └─ Toxicity prediction: побочные эффекты
├─ Genomic Medicine:
│  ├─ Variant interpretation: патогенный или benign?
│  ├─ Disease risk prediction: polygenic risk scores
│  └─ Pharmacogenomics: какие лекарства подойдут
└─ Image Analysis:
   ├─ Microscopy: cell counting, phenotype classification
   └─ Pathology: tumor detection, grading

Applications (Применения):

1. Персонализированная медицина:
   ├─ Cancer genomics: мутации опухоли → таргетная терапия
   ├─ Rare diseases: диагностика через WGS/WES
   ├─ Pharmacogenomics: дозировка лекарств по генетике
   └─ Preventive medicine: genetic risk scores

2. Drug Discovery:
   ├─ Target identification: какие белки атаковать
   ├─ Virtual screening: in silico отбор молекул
   ├─ Clinical trial optimization: stratification пациентов
   └─ Repurposing: новые применения старых лекарств

3. Agriculture:
   ├─ Crop improvement: genomic selection
   ├─ Livestock breeding: генетика для productivity
   ├─ Disease resistance: идентификация устойчивых вариантов
   └─ GMO: генетическая модификация культур

4. Evolutionary Biology:
   ├─ Phylogenetics: эволюционные деревья
   ├─ Population genetics: миграции, смешения
   ├─ Ancient DNA: неандертальцы, денисовцы
   └─ Metagenomics: микробные сообщества

5. Synthetic Biology:
   ├─ Gene editing: CRISPR-Cas9
   ├─ Metabolic engineering: микроорганизмы производят лекарства
   ├─ De novo gene synthesis: создание искусственных генов
   └─ Biofuels: бактерии производят топливо

6. Forensics & Ancestry:
   ├─ DNA fingerprinting: идентификация личности
   ├─ Ancestry testing: 23andMe, AncestryDNA
   └─ Paternity testing

ПРОБЛЕМА: ИНТЕРПРЕТАЦИЯ

Мы знаем:
• 3 млрд пар оснований в геноме
• ~20,000 генов

НО не знаем:
• Функцию большинства генов (30-40% unknown function)
• Что делают 98.5% некодирующей ДНК (junk DNA?)
• Как гены взаимодействуют (networks)
• Epigenetics: регуляция без изменения ДНК

Вариации:
• Каждый человек: 4-5 млн вариантов от reference genome
• Variants of Unknown Significance (VUS): большинство
• Pathogenic vs Benign: сложно определить

CHALLENGES:

1. Missing heritability:
   GWAS находят варианты, но объясняют малую часть наследуемости
   Пример: рост человека — 80% heritability, но найдено только 20-30%

2. Polygenic traits:
   Большинство признаков: множество генов с малым эффектом
   Нельзя просто "найти ген диабета" — это сотни генов

3. Gene-environment interactions:
   Genetics + environment → phenotype
   Сложно разделить

4. Rare variants:
   Многие болезни: редкие варианты в разных генах
   Требуются огромные cohorts для изучения

AlphaFold — прорыв:
2020: AlphaFold2 решает protein folding
→ Предсказывает 3D структуру белка из последовательности
→ 200 млн структур предсказано
→ НО: структура ≠ функция полностью

БУДУЩЕЕ:

Оптимистично:
• Multi-omics: геном + транскриптом + протеом + метаболом
• Single-cell: понимание на уровне отдельных клеток
• AI: интеграция всех данных для понимания
• CRISPR: возможность править геном (терапия)

Реалистично:
• Incremental progress: медленное накопление знаний
• Low-hanging fruit собраны: дальше сложнее
• Interpretation bottleneck: секвенирование дешевое, анализ — дорогой

Этически сложно:
• Privacy: genetic discrimination
• Equity: access to genomic medicine
• Designer babies: где граница?

ЗАКЛЮЧЕНИЕ:

Биоинформатика находится на пересечении biology, computer science, и statistics.
Секвенирование стало дёшевым, генерируя tsunami данных.

НО: от данных к знаниям — долгий путь.
Reading the genome ≠ Understanding the genome.

Следующий grand challenge: functional genomics.
Не "какие гены есть", а "что они делают и как взаимодействуют".

"Геном — это книга жизни. Мы научились читать слова,
